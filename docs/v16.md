# v16

> パーティクルフィルタ(PF)を**全体**ニューラルネットに置き換える実験。
> 「一部置換(残差学習)」では小改善どまりだったため、PFのアルゴリズムそのものを学習モデルで代替する。
> 最終更新: 2026-06-30

## 仮説
- PF = 「可変参照(typewell)に対するGR照合(尤度)」+「dip動力学による系列の整合化(再帰)」を行う再帰推定器。
- これを **end-to-end 学習**に置き換えれば、(1) PFパラメータの過学習(Optuna)を回避でき、
  (2) GR照合を手作り尤度でなく**学習マルチスケール照合**にでき、(3) train評価ゾーンの真TVT全行で
  教師ありにできる → v9(LB 6.946)を独立系統で上回る/強く補完できるのではないか。

## 定式化(A/B 共通)
- 状態 `s = TVT + Z`(構造絶対深度, MDに対し滑らか)。
- 幾何ベースライン `s_base(MD)` = 既知ゾーン末尾(直近 `DIP_FIT_N=300` 点)の dip を線形外挿。
- モデルは**残差** `r = s_true - s_base` を学習(動的レンジ小・アンカーが自然に入る)。
- 最終予測 `TVT = s_base + r - Z`。
- GR欠損は前後補間(v16外部解の知見: NaN多発坑井で致命的)。
- test互換: 使う列は `MD,X,Y,Z,GR,TVT_input` と typewell のみ(ANCC〜BUDA/TVT非依存)。

## 案A: 学習型再帰フィルタ(GRU + cross-attention)
- typewell GR → 1D-CNN → メモリ(key/value、value に正規化TVTを付与)。
- 水平点: GR窓埋め込み + 幾何(`z_rel, md_rel, sbase_rel, known`) → query。
- cross-attention(`key_padding_mask`でtypewellパディング無効化) → 学習版GR尤度コンテキスト。
- GRU が predict-update の再帰を学習 → 残差 r を出力。
- PF→NNの**直訳**。実装が軽く学習が安定。弱点: 多峰の曖昧性保持はBより弱く平滑化に倒れがち。

## 案B: 微分可能DP / soft-Viterbi(PFの最も忠実なNN化)
- 状態 = baseline TVT(`s_base - Z`)からの残差 offset。バンド `±BAND=60ft`、分解能 `dt=1.5ft`(K=81状態)。
- **emission(尤度)**: 水平GR埋め込み と typewell埋め込みを `baseline+offset` のTVTで `batched_interp` サンプルして内積
  (学習マルチスケールGR照合)。温度 `log_temp` 学習。
- **transition(dip動力学)**: `logT[k,k'] = -(off_k-off_k')^2/(2 sig^2)`(残差の平滑性)。`sig` 学習。
- **soft forward-backward(sum-product, log空間)** → 周辺事後 gamma → 期待 offset を読み出し(全微分可能)。
- 経路は非単調OK(素のDTWではない)。PFのサンプリング近似を厳密DPに置換した形。
- 注意: DPは H(クロップ長)×K の**逐次**計算。検証は全長で走るため**長い坑井で遅い**。crop/K/batchで調整。

## 過学習対策(我々の持病=CV-LB乖離への備え)
- 学習はランダムクロップ + 既知/評価境界をまたぐ窓で augment。
- **理想は typewellグループ単位の hold-out**(同一フィールド漏れ防止)。現状の `run_cv` は well 単位GroupKFold。
  → 同一typewell検出ができたらグループKFoldへ差し替える(別途EDA予定)。
- 残差ターゲット + 強い transition 平滑性で多峰のぼけ/暴れを抑制。

## 結果: 案A・案B とも不調(2026-06-30)
- **案A(GRU+cross-attention)・案B(微分可能DP) どちらもうまくいかなかった。** v9(CV≈7.99 / LB6.946)を超えられず採用見送り。
- 学び: PFを直接NNに「全置換」する方向(逐次フィルタ/DPをそのまま学習)は、この問題設定では伸びなかった。
  → 発想を変え、**「物理で候補軌跡を生成し、学習(CNN)で選択する」分解**(v17)へ移行。
