# v44 — GeoSteerNet(SDF-CNN)に物理prior(struct)を注入

> **状態: ローカル稼働・struct注入実装済・スモーク通過(本格学習は未)。** ユーザー提供の
> `rogii-cnn-mtp-train.ipynb`(GeoSteerNet, hengck23派生)をローカル化し、struct物理priorを注入。

## 元notebookの正体
GRマッチ画像 `H(z,x)`(z=typewell TVT深度, x=坑井位置)から U-Net CNN が **SDF(符号付き距離場)**
`sdf[z,x]=(h_tvt[x]−t_tvt[z])/40` を予測 → ゼロ等値面=境界=TVT。**MTP**(K=5モード+logit)でbimodal datum対応。
= v43(PF-free HMM画像DP)の**学習CNN版**。評価は元来 row-RMSE(bin単位)。

## 物理prior注入(ユーザーの問い「事前分布として物理モデルを適用したら?」)
- **struct-SDF を第6チャネル(ch5)として追加**: `sdf_prior[z,x]=(tvt_prior[x]−t_tvt[z])/40`、
  tvt_prior = 履歴帯=既知TVT / **未来帯=struct予測(v38 K16 dip場)**。= ch3(履歴TVT-diff)を eval帯へ
  structで延長した「期待境界SDF」。v39の残差背骨のSDF版。CNNが GR証拠(ch2)+ struct prior(ch5)を融合。
- `V44_STRUCT=1` で ch5 追加(in_ch 5→6)。offset対応(struct[offset:]をafter binningに整列)。

## ローカル化(実行できるように作った)
- src/*.py 抽出(config/dataset/model_sdf_mtp/engine…)、パスをlocal化、外部依存 meta_df を再構築(`v44/meta_df.csv`=坑井別 typewell t_step)。
- **単GPU学習ドライバ `v44/train_local_v44.py`**(engine のDDPは不使用)。評価= pred_rows(top1)→ t_tvt[row]
  でTVTに戻し **未来帯 pooled TVT-RMSE**(≈コンペ指標, resampled bin近似)。baseline(in_ch5) vs +struct(in_ch6) ablation。

## 早期スモーク(2ep/48坑井 = トイ値, FAST_DEBUG)
| | val TVT-RMSE(未来帯) |
|---|---|
| baseline(in_ch5) | ~18.1 |
| **+struct(in_ch6)** | ~15.8(ep0=**12.97**) |
→ **struct-SDFチャネルで初手から大幅に低い**=物理priorがCNNに効く方向は明確(本学習で確定)。

## 実行
```
# baseline
EPOCHS=40 python v44/train_local_v44.py
# +struct(物理prior注入)
EPOCHS=40 V44_STRUCT=1 python v44/train_local_v44.py
# 比較: 未来帯 val TVT-RMSE の baseline vs struct
```
FAST_DEBUG=1 で 40坑井/少epoch のスモーク。本番は全坑井・EPOCHS40〜50・K=5(MTP)。

## 所感 / 次
- v43(非学習HMM画像DP)は struct に張り付き 9.7 だったが、**CNNは学習で GR画像から more を引ける**のが賭け。
  早期スモークは struct注入が効く兆候。本学習で baseline vs struct の差が確定する。
- 評価が row/未来帯bin の近似なので、最終的には元eval行に戻した overall pooled TVT RMSE で他エンジンと比較要。
- 効けば PF資産に一切依存しない別系統エンジン(バンク素材/アンサンブル)。MTPのモードは datum両義素材。
