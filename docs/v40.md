# v40 — 微分可能グリッド・ベイズフィルタ(学習型emission × 物理prior)

> **状態: 実装中。** ファイル: `v40/train_grid_filter_v40.py`。
> 幾何prior路線の第3弾([[v38]]=PF錨, [[v39]]=NN背骨 に続く)。PF+prior+学習の本命。

## 仮説
固定PFの GR尤度は手作りの `exp(-0.5((gr−typewell(tvt))/gs)²)`。これを**学習型の観測モデル**に置き換え、
**物理prior(構造幾何)で暴走を止めつつ end-to-end で真TVTに最適化**すれば、
「行ごとにGRを信じるか構造に任せるか」を学習でき、多峰性(bimodal datum)を保ったまま硬い核を叩ける。

## アーキテクチャ
**フィルタ = グリッドHMM(前向きメッセージ伝播, 完全微分可能)。**
カルマン(単峰)/微分可能PF(不安定)を却下。信念=グリッド上の分布で多峰性を保つ。検証の厳密HMMスムーザの学習版。

- **状態 = 構造priorからの偏差グリッド `d`**(±32ft, 0.5ft刻み=129ビン)。struct軌跡を中心に据える
  → グリッド小・"d=0=幾何に従う"が原点。struct が運動の平均を担うので遷移は偏差の拡散のみ。
- **物理prior(アンカー, 2箇所)**:
  - 初期信念 = softmax(−0.5(d/sig_struct₀)²)(構造priorそのもの)。
  - 各ステップで構造prior `N(0,sig_struct_t)` へ緩くリーク(leak率 学習)。近傍ドナー密=sig小→強く引く。
  - 遷移 = 拡散カーネル畳み込み(幅 学習)。
- **学習型emission = 共有小TCN**。入力=**局所・相対のGR文脈のみ**(gr正規化/勾配/typewell局所std=識別力/sig)
  → 各行の **信頼ゲート ωₜ・スケール σₜ** を出力。電位 `L[t,k]=ωₜ·(−0.5·(gr_t−typewell(struct_t+d_k))²/σₜ²)`。
  aliased GR行 → ω→0 → 構造priorへフォールバック(硬い核を直接叩く)。
- **★転移安全性を設計で保証**: emission NN は XY/field/well-id を一切見ない局所入力のみ → **フィールド指紋を
  記憶不能**([[v37-ranker-deep]]の過学習の反省)。PFの尤度が全坑井共有なのと同じ理屈で、中容量でも転移する。

## 更新式(前向き)
```
belief0 = softmax(-0.5 (d/sig0)^2)
for t: bp = belief @ Tmat(diff); bp = (1-leak)*bp + leak*prior_t; bp/=sum
       L = gate_t * (-0.5 ((gr_t - eg[t,:])/sig_t)^2);  belief = softmax_grid(log bp + L)
       pred_dev_t = sum(belief * d)
pred_tvt = struct_tvt + pred_dev
```
eg[t,k]=typewell(struct_tvt[t]+d_k)(坑井ごとに前計算, fp16キャッシュ)。損失=masked MSE(pred_tvt, true)。
