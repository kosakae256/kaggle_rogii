# v104 — 「多様性を保ったまま冗長/ノイズだけ削る」剪定 + anchor-free dec10(sharp/smooth)追加

## 位置づけ(重要)
- **最終提出は v103 と v104 の2枠**。**アンサンブルしない**。Kaggle の最終2選択に、それぞれ独立の (TCN+L5) 提出を充てる。
- v103 = 15バンク + dec10 + tw-affine(TCN 学習完了で提出可)。
- **v104 = v103 をベースに「剪定 + sharp/smooth 追加」した別モデル**。同じく (TCN+L5)。
- **時短のため v104 は決定版 GroupKFold(5-fold)のみ**(v103 のような gseed×K grid はやらない)。残時間が少ないため急ぐ。

## 仮説
L5 は bagging 型で**多様性が命**([[l5x-candidate]]: 候補剪定 prune58/top-k は全部悪化)。
→ 素朴に候補を減らすのは逆風。だが **「全PFにとって冗長 / 精度が低くノイズになっている推論軌跡・特徴」** は、
多様性をほとんど落とさずに削れる可能性がある。これを**仮説→剪定→L5学習→OOF評価のループ**で1つずつ検証する。
併せて **anchor-free dec10(sharp/smooth)を脱相関候補として追加**して底上げする。

例(初手仮説): `self_graft` は単体精度が全体的に低い。全PFにとって冗長な表現になっている可能性
→ 全PFの self_graft 候補を抜いて L5 を学習し、OOF が悪化しないか(むしろ改善するか)を見る。

## 変更点(v103 から)
1. **+ sharp / smooth(anchor-free dec10)を【6表現】**: 他PFと同様に raw dec10 5表現(tw/self/nbr/nbr_gr5/self_graft)
   + affine_tw(affine_dec10, tw)= **6表現 × 2バンク(sharp=1/smooth=2)= 12候補**を L5 candidate に追加。
   - 列: `decaf_{5rep}_delta/std_{1,2}` + `affdec_ancc_delta/std_{1,2}`。
   - **再生成が必要なのはこの dec10 軽量特徴だけ**。train は生成済み(`artifacts_v103/fwd/dec10af_train_lean.parquet` 26列)、test は submit 時に生成。jumpy 不採用。
   - sharp×smooth 相関 0.927 だが anchor-free ゆえ既存15バンク(錨あり)と脱相関の見込み。
2. **候補/特徴の剪定(ルールベース・仮説駆動ループ)**: v103 の候補セットから、仮説に合う候補を除外。
   - 粒度: 表現単位(例 self_graft を全PFから)/ バンク単位 / 候補トークン単位、を仮説ごとに選ぶ。
   - 判定は **det GroupKFold 5-fold・5seed の OOF overall RMSE**(v103 base=5.5549 が基準)。悪化しなければ採用(=多様性を落とさず軽量化)。
3. **v103 特徴は再生成しない**(15バンク+dec10+tw-affine の parquet を流用)。

## 手法の概要(実装方針)
- **候補セットをパラメータ化**した `train_v104.py`:
  - base = v103 の ED/ES(51+dec5+tw-affine15)+ **sharp/smooth 追加** − **PRUNE(仮説で除外する候補パターン)**。
  - `SF_EXTRA` に v103 の4 parquet + `dec10af_train.parquet` を追加。
  - seqfeat → L5(det GroupKFold, 5seed)。OSUF は仮説ごとに変える(比較用)。
- **剪定ループ**: 仮説(除外パターン)を変えて上記を回し、OOF を並べて比較。多様性維持=悪化しない剪定のみ残す。
- **TCN**: L5 で有効だった剪定/追加を features に反映して学習(**L5 で確定してから**。L5 で削った特徴は TCN 側でも削ると効く可能性=後で確認)。
- **提出**: `submit_v104.ipynb`(v103 submit を土台。候補セットを v104 用=sharp/smooth 追加+剪定 に差替。det L5 ckpt + TCN ckpt + 後処理 expansion 較正)。

## L5R+ext 探索(構造化attention + 脱相関候補注入)= L5飽和の最終確認

### 狙い
L5 は「選択器」でなく**適応的アンサンブラ(soft加重平均=bagging)**([[l5x-candidate-crossattn]])。同じPF候補を再処理しても corr~0.99 で頭打ち。
そこで **L5R** = L5 に (a)候補の構造埋込(leg/rep/family/k)+ (b)候補間 relational attention を足し、さらに
**ext候補**として TCN OOF δ と 物理錨 δ を候補注入(別情報源)して脱相関を狙った。

### 結果(すべて重み0=不採用)
1. **L5R(ext無, 103候補)= 5.5561**。構造化attentionだけでは改善せず(≈L5)。
2. **L5R+ext(tcn+anchor入力, 91候補)= 5.5436**。ext注入で単体は L5det(5.5549)を −0.034 上回る(構造+ext は単体には効く)。だが **corr vs L5grid=0.997**。全脚ブレンドでは **重み0**(L5gridと冗長)。
3. **ユーザーの指摘で判明**: TCN を L5R入力に食わせると、出力ブレンドでの TCN の伸びが激減(食う版 Δ−0.013 vs 食わない版 Δ−0.033〜−0.055)。= **TCN の脱相関を「使い切る」二重計上**。
4. **anchor-only L5R(TCN入力を外す)= 5.6029**。狙い通り TCN出力伸びは倍増(−0.033→−0.061)したが、単体劣化を取り戻せず、やはり L5grid に勝てず **重み0**。

### 結論
**構造化attention + 物理錨候補 + TCN候補 でも、L5系は L5grid と脱相関せず全滅(重み0)**。
= [[deep-research-ceiling-2026-08]] の「datum壁で L5系飽和」を実証で再確認。extR は最終提出から除外。
