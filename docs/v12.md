# v12

> 1D-TCN(双方向 dilated CNN, seq2seq)で TVT を予測。v10 の特徴量(順方向PF+逆方向PF+比較)を
> 坑井ごとの系列入力として使い、5-fold GroupKFold で CV を確認する。
> 最終更新: 2026-06-28

## 仮説
- 順方向PF + 逆方向PF を系列の入力チャンネルに与え、CNN に「どこで順方向/逆方向を信じるか」を
  局所的に学習させる(= 学習可能な forward-backward 平滑化)。
- LightGBM は行を独立に見るが、TVT は MD 方向に連続。系列モデル(TCN)で連続性・局所文脈を活かす。

## データ / 入力
- **v10 の `artifacts_v10/data/train.parquet` を使用**(順方向PF + 逆方向PF `bpf_*` + 比較 `cmp_*` + 非PF特徴)。
- 坑井ごとに行(評価ゾーン)を MD 順の系列に整形。数値特徴を全チャンネルとして入力 `(F, T)`。
- `well`/`id`/`target` は入力から除外。target = TVT - last_tvt(相対)。
- 標準化は **fold の train 坑井から算出**(running sum、リーク無し)。欠損は標準化後 0 補完。

## モデル
- 双方向(non-causal, same-padding)dilated 1D-CNN(TCN)。
  `HIDDEN=96, LEVELS=7(dilation 1..64), KERNEL=3, DROPOUT=0.1`、残差ブロック、GELU。
- 出力: 各MD位置の target。損失 = マスク付きMSE(パディング除外)。
- 学習: Adam(lr=1e-3, wd=1e-5)、grad clip=1.0、early stopping(patience=8)、最大40エポック。

## CV / 評価
- **GroupKFold(5) by well**(リーク防止)。
- OOF 全行プールの **overall RMSE**(Kaggle指標に整合)+ 参考に坑井平均RMSE。
- OOF を `artifacts_v12/oof_tcn.npy` に保存(後で LightGBM とブレンド可能)。

## ファイル
- [v12/train_tcn_v12.ipynb](../v12/train_tcn_v12.ipynb) … 上記の学習・5foldCV(ノートブック)。

## 結果
- fold RMSE: [7.808, 8.161, 6.782, 7.331, 9.086]  / mean fold = 7.834
- **overall RMSE = 7.871**(Kaggle整合)/ per-well mean = 6.330(参考)
- OOF: `artifacts_v12/oof_tcn.npy`
- 所感:
  - TCN単独(overall 7.87)は LGBM(v10)より弱い。773坑井は深層には小さく、PF特徴入りLGBMが強いため想定内。
  - overall(7.87) ≫ per-well(6.33) の乖離が大きい = **行数の多い(長い)坑井で誤差が大きい**
    (長い坑井で系列が drift?)。改善余地はここ。
  - fold分散が大きい(6.78〜9.09)= 小データで不安定。
  - 真価は**ブレンド/スタッキング**。

## ブレンド結果(LGBM v10(2) × TCN v12, OOF加重平均)
- LGBM単独 7.5537 / TCN単独 7.8710 / OOF相関 0.9534
- **best w(LGBM)=0.64 → overall 7.3924(Δ=-0.161)**。相関は高いが誤差が部分的に直交 → ブレンド有効。
- ノート: [v12/blend_lgbm_tcn.ipynb](../v12/blend_lgbm_tcn.ipynb)
- 次手: **スタッキング**(TCN OOF を `tcn_pred` 特徴として LGBM に入力)。ブレンド以上を期待。
  ノート: [v12/stack_lgbm_tcn.ipynb](../v12/stack_lgbm_tcn.ipynb)

## メモ
- 773坑井と小さめ → 過学習注意。dropout / early stopping / well単位CV で対処。
- LightGBM(v10)の OOF とブレンドすると伸びる可能性(モデル系統が違うため)。
- 入力特徴数 F が多い(数百)とメモリを食う。重ければ特徴を絞る or float32 のまま運用。
