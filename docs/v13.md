# v13

> PF(順方向+逆方向)の「全軌跡」を 2D 画像化し、2D-U-Net で TVT を予測する実験。
> v10(逆方向PFが効いた)・v12(1D-TCN)の発展。**pf_1 簡易実験 → pf_1/2/3 へ拡張**。
> 最終更新: 2026-06-29

## 仮説
- v10 で逆方向PFが効いた。PF出力を「平均+std」に潰さず、**全軌跡を 2D画像(MD × 相対TVT)**にして
  2D-U-Net に入れれば、多峰性・不確実性の形まで使えて精度が上がるのでは。
- 順方向PF平均を中心(y=0)にバンドを取り、U-Net は「順方向事前からのズレ(稜線)」を学ぶ。
  = 学習可能な forward-backward 平滑化 / コストボリューム上の経路探索。

## パイプライン(2段に分離 ★重要)
PF生成(重い・GPU)と 画像生成(軽い・CPU)を分離。**PFを再実行せず画像設定を変えられる**。
パスは `v13/artifacts_v13/` に統一。

1. **PF生成(重い, 1回だけ)**: [v13/create_pf_images_v13.py](../v13/create_pf_images_v13.py)
   - GPUで **pf_1/2/3 の各**順方向PF(32本)+ 逆方向PF(各終端から4本=128本)を実行。
   - 各坑井 `v13/artifacts_v13/img/{well}.npz` に保存:
     - **per-seed 生波形** `fwd_traj_pf_1/2/3`(32,T) / `bwd_traj_pf_1/2/3`(128,T)(絶対TVT, f16)← 復元・使い回し可
     - alias `fwd_traj`/`bwd_traj` = pf_1(可視化/解析互換)
     - `center`(=pf_1 順方向アンサンブル, **全セット共通のバンド中心**), `target_rel`(真TVT−center), `ev_index`, `last_tvt`
2. **画像生成(軽い, 何度でも)**: [v13/build_images_v13.py](../v13/build_images_v13.py)
   - 保存波形から **バンド/ビン幅/チャンネルを変えて画像だけ再構成**(PF不要)。
   - チャンネル: **各セットの fwd/bwd 密度 + GRコスト(共通)** = 最大7ch
     (順: pf_1 fwd, pf_1 bwd, pf_2 fwd, pf_2 bwd, pf_3 fwd, pf_3 bwd, grcost)。
   - 出力 `v13/artifacts_v13/images/{well}.npz`: `img(C,H,T)`, `target_rel`, `mask`, `center`, `ev_index`, `last_tvt`, `band/binw/H/channels`。

## 画像仕様
- 軸: x=MD方向(評価ゾーン行), y=中心からの相対TVT(ft)。中心(y=0)=順方向PF平均。
- チャンネル(可変, `CHANNELS`):
  - `fwd`: 順方向トラジェクトリ密度(KDEヒストグラム)
  - `bwd`: 逆方向トラジェクトリ密度
  - `grcost`: GR残差コストマップ |観測GR − typewell GR(候補TVT)|(=GRの入力)
- バンド: `BAND`(±ft), `BINW`(ft/px)。**1px = BINW ft**。
  - 採用: **`BAND=32`, `BINW=0.5` → H=129**(±32ft, 1px=0.5ft)。build_images_v13.py で設定。
- ターゲット(train): `target_rel`(真TVTの中心相対ft, バンド非依存)。`mask`=|target_rel|≤BAND。

## 学習(2D-U-Net)
- [v13/train_unet_v13.ipynb](../v13/train_unet_v13.ipynb)
  - 入力 `artifacts_v13/images/{well}.npz`。2D U-Net(3レベル, GELU/BN, デコーダは interpolate)。
  - 出力 (H,T) ヒートマップ → 各MD列で H方向 softmax → **soft-argmax** で連続オフセット(ft)。
    予測TVT = center + オフセット。
  - 学習: T方向ランダムクロップ(CROP=1024, VRAM対策)、損失=マスク付きCE + soft-argmax MSE、early stopping。
  - 評価: **GroupKFold(5) by well**、坑井ごと全長推論 → OOF全行プールの **overall RMSE**
    (target_rel基準 = TVT RMSE)。OOF を `artifacts_v13/oof_unet.npz`(well→pred_rel)に保存。
- 画像のメタ(H/band/binw)は npz から自動取得するので、build_images の設定変更に追従。

## 別仮説: 順×逆の一致度が高い波形ほど真に近い?
- [v13/agreement_experiment_v13.ipynb](../v13/agreement_experiment_v13.ipynb)(保存済みPF波形のみ・PF/U-Net不要)
- 逆方向128 = 順方向32×各4。`fwd[i]`↔`bwd[i,j]` の128ペアで一致度 `rmse(fwd,bwd)` を測り、**最一致K(=5)ペア**を採用。
- 予測候補: A=採用順方向の平均 / B=採用(順+逆)/2 の平均 / AB=A,B平均。**ベースライン=順方向32本の単純平均**。
- 各案の overall RMSE を比較(K=1,3,5,10,20 の傾向も)。仮説が効けば base より下がる。
- **結果(不成立)**: 順方向32本単純平均=9.878。一致上位5は **悪化**(順=10.43 / 順+逆=10.20 / AB=10.23)。
  一方 **尤度加重平均(pf_ancc)=9.188 が最良**(−0.69)。
- 所感: 「fwd×bwd一致=真」は不成立。一致は確信度であって正確さではなく、両方が同じ誤モードに揃いうる。
  選別軸は **一致度ではなく GR尤度**が正。5本選抜は平均化(分散低減)も失う。

## 結果(U-Net, band=32/binw=0.5)
- **pf_1のみ(3ch)**: overall RMSE = **8.583** / per-well 6.691
- **pf_1/2/3(7ch)**: fold [8.599, 8.264, 7.332, 6.741, 10.316] / mean 8.250 /
  **overall RMSE = 8.337** / per-well 6.277 → 3セットで Δ-0.25 改善(PF情報増が効く)
- 参考: v10(LGBM,2)=7.554 / v12(TCN)=7.871 / v10×v12ブレンド=7.392
- 所感:
  - 3モデルで最弱。ただし **pf_1のみ**(v10/v12は3セット)+ **v9タブ特徴を捨てている** + **band=32が難坑井で狭い**、のハンデ込み。
  - overall(8.58)≫per-well(6.69) → 長い/難しい坑井で誤差大(band外クリップの可能性)。
  - 改善余地: band拡張(PF不要で再ビルド可)/ 3PFセット化(ch増)/ 学習長め。
  - 本命は **アンサンブル多様性**: v10/v12 と OOF ブレンドで overall<7.39 を下回れるか検証。
