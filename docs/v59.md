## 結論(GR-free戦線 close)
1. **GR-freeの天井 ≈ struct 9.7**。prefix錨後に残るGR-free情報は
   ①own dip外挿(structが保有) ②面の絶対レベル(**井戸沿い自己相関バイアス場** — 行レベル融合は
   フィルタがバイアスに追従して観測水準(~15)へ吸われる。使える成分は錨1本分= b̂が搾取済み)
   ③近傍dip場(積分でノイズ線形増幅=C 78.6)。**学習(NN)を載せても学習すべき残差構造が無い**(P1で確認)。
2. Kalman融合の教訓: **自己相関バイアスを持つ観測は白色ノイズ扱いすると吸収される**(qを下げると純structに退化=情報ゼロの証明)。
3. 生き残り: σ(dist)=信頼度としてのv54注入 / 面×structの井戸レベル相補性(51/188)は
   hard検出0.6壁の向こう側(行レベル・固定則では取れないことを全形式で確認)。
4. 改善の唯一の道はデータ密度(井戸間隔<300ftなら面5ft級)— コンペでは変えられない。
