# v102(計画メモ)— ps_combo(錨カーネル seed再加重)を全PFに適用 → TCN/L5

> ★まだ着手しない。後でやる可能性が高い計画。v101 の seed集約実験([v101.md](v101.md))の結論を製品化する版。

## 仮説
単体PFの 32 seed 集約を、現行の「尤度加重平均」から **ps_combo(尤度 × 錨カーネル)** に置き換えると、
双峰 datum 井で正しい枝側へ寄って単体PFが改善(v96 6バンクで −0.27 overall)。その改善済みバンクを
**create に流して TCN / L5 に通す**と、blend も上がるかを見る。

## 手法(製品化)
- 各バンクの seed 集約重みを:
  ```
  ww_new  = ww · exp( − d_anchor²(seed) / (2·τ²) )        # τ=6ft
  d_anchor(seed) = mean_over_eval_rows( (seed軌跡 − 錨TVT)² )
  pred = Σ ww_new · seed軌跡
  ```
  を `run_smoother_ext` の seed 集約(pf_banks_v95.py:554-560 / full分岐 500-504)に**1行追加**(env トグル)。
- **錨TVT = GRフリー錨**(`pf._ANCHOR[wid]["tvt"]` = grfree_anchor_train.pkl / test は gen_grfree_test_anchor)。
  = emission の帯中心 `_st` と同一。非physicsバンクは通常 anc OFF なので、集約用に別途この錨を渡す必要あり。
- create(v96/v97/v100 全15バンク)で ps_combo 集約 → train_combo 再生成 → **TCN + L5 再学習** → blend。

## ★重要な caveat(v101 実測、盲目適用しない)
ps_combo は**バンクで効き方が正反対**(v96 6バンク, pfw, emission ON):

| 効く(Δ<0=適用) | 効かない(Δ≥0=適用しない) |
|---|---|
| pf_2 **−1.04** / pf_1 −0.23 / pf_3 −0.24 / r1 −0.24 | r0 +0.05 / **pfA +0.25(physics錨mult20で二重計上)** |

→ **弱い/多峰バンクに効き、既に錨を使うバンク(pfA)や強いバンク(r0)は悪化**。
「全PFに適用」でなく **per-bank on/off(train-Δ<0 のバンクだけ)** が正しい。バンク固有性質なので train 判定が test 転移。
v97/v100 バンクは emission 強め=効きが小さい可能性、要 per-bank 実測(v101/exp_seed_modes_v101.py で Δ を出す)。

## 期待値較正
- 単体PF −0.27 は blend(CV5.5871)を通ると希釈 → 現実天井 **v34規模(~-0.04 LB)**。判定は blend-CV。
- **学習ブレンダーは手作り ps_combo に負けた**([[v101-seed-mode-anchor]])= 学習は使わず1行カーネルで十分。効く信号は錨のみ、oracle(5.43)は蜃気楼。
