# v21 — Particle Filter に NN を挟む(学習尤度 / 学習遷移)

> **狙い**: PFの骨格(逐次ベイズ更新+リサンプリング=効いている部分)は残し、構成要素を1つだけ学習モジュールに差し替える。
> v16「PF全置換」は失敗したので、**最小侵襲で“どこにNNを挟むと効くか”を切り分ける**。
> パラメータは **v19バンクの r0 のみ**で実験(物理項は既定OFF=NN効果を切り分けるため)。
> 評価はノイズ床(±0.2)を踏まえ、**硬い核の per-well RMSE(桁変化)** と **train overall(全行プール)** で見る。LBの0.05差では判断しない。
> 最終更新: 2026-06-30

## 背景(これまでの結論)
- PFは GR を typewell に照合して `geo_z=TVT+Z`(構造深度)を逐次推定。LB ~7.0 で頭打ち([[scores]])。
- 最大の失敗= **ラテラルで水平化(dip→0)するのに known dip を外挿して行き過ぎる**(硬い核診断, [docs/hard_wells.md](hard_wells.md))。
- もう一つ= **GRが多義的(エイリアス)/ typewell非代表**で尤度が嘘をつく。
- 選択(どのPF/粒子を信じるか)は坑井内情報では学習不能(signal_compare 等で3連敗)。直交情報=構造。

→ **PFの2要素(観測尤度・遷移)を学習化**して、上の2失敗を直接attackする。

## 案A: 観測尤度を学習(ニューラル・マッチャー)
- 現状: `lk = exp(-0.5*((GR_obs − GR_tw(at tvt))/gs)^power)`(点GR距離)。
- 置換: **学習コストマップ** `Lmap[md_i, tvt_grid]` を matcher NN が出す。
  - matcher: 水平GR窓(MD周辺) × typewell GR窓(候補tvt周辺) → マッチ log尤度。Siamese 1D-CNN。
  - 学習: trainの真 `tvt` を正解位置に、他位置を負例にコントラスト学習(**PF微分は不要**)。
  - PF: 粒子位置 tvt → grid index で `Lmap` を lookup して尤度に使う(**NNはPFの外で1回/坑井だけ走る=速い**)。
- 狙う失敗: **GRエイリアス**(点でなく窓＋文脈で多義性を解消)。docs「点GRは弱い→窓NCC」のNN版。

## 案B: 遷移(dip事前)を学習
- 現状: `rate_n = α·rate + ノイズ (+ 物理項=known dipへ引き戻し)`。
- 置換: **学習ドリフト** `drift[md_i]` を transition NN が出し、`rate_n = (1−λ)·(α·rate) + λ·drift + ノイズ` に混ぜる。
  - transition: 入力=MD_since_known(ラテラル進行度)/直近dip/GRトレンド/(任意)構造prior。出力=期待dip。MLP。
  - 学習: trainの真 `geo_z` 増分を回帰(**PF微分不要**, NNはPFの外で1回/坑井)。
- 狙う失敗: **過外挿**(「普遍的に水平化＋構造に沿う」を学習し、行き過ぎを抑える)。物理項の代替・改良。

## 設計(共通エンジン)
- [v21/v21_common.py](../v21/v21_common.py): r0パラメータ・坑井データ準備・**lmap/drift を差せる GPU PF**・評価。
  - `_pf_core(..., lmap=None, drift=None, lam=0.0)`: lmap指定で尤度を学習版に、drift指定で遷移を学習版に差し替え。両方Noneなら素のr0 PF。
  - `run_forward(...)`: 坑井×シードをバッチ化、lmap/driftは坑井ごと→well_indexで参照。
  - `eval_wells(...)`: 指定坑井で overall(全行プール)RMSE と per-well RMSE。
- ノート:
  - [v21/v21A_neural_likelihood.ipynb](../v21/v21A_neural_likelihood.ipynb): matcherの学習→Lmap生成→PF評価。
  - [v21/v21B_neural_transition.ipynb](../v21/v21B_neural_transition.ipynb): transitionの学習→drift生成→PF評価。
- 実験規模: **r0のみ・坑井サブセット(易+硬い核20件)・小シード**でまず手応えを見る。

## 評価設計
- 基準: 素のr0 PF(lmap/drift=None)の overall RMSE と per-well。
- A/B それぞれ ON にして、**(1) overall が下がるか (2) 硬い核20件の per-well が桁で改善するか**。
- ノイズ床±0.2を超える変化のみ「効いた」と判断。効けば A×B 併用、さらに構造prior強化へ。

## 結果 — 案A/B は【論外】（2026-07-01）
- **v21 の具体実装（案A=ニューラル尤度マッチャー / 案B=学習ドリフト遷移）はダメ**。素のr0 PF を超えられず＝論外。
- ただし **「PFにNNを組み込む」という方向そのものは死んでいない**。あくまで *この2つの挟み方* が外れただけ。
  - 実際、**PF出力の残差をNN/GBMで学習する（残差学習）路線は一応スコアが出る**（v9系の apply_pp 等が既にそれ）。
  - → A/B（尤度・遷移の直接置換, PF微分なし・坑井外で1回）が弱かったのであって、NN×PF の設計余地は別にある（下記）。

## PF×NN は別の挟み方を残す（オープン）
- A/B が外れた理由の見立て: **PFの外で坑井ごとに1回 NN を回す“静的差し替え”**だと、PFの逐次性・粒子の文脈を活かせず、結局「GR尤度≠真値」の壁に同じくぶつかる。
- まだ試していない挟み方の例（要検討、優先度は別途）:
  - **微分可能PF（end-to-end）**: リサンプリングを soft（Gumbel-softmax/OT）にしてPF全体を通して誤差逆伝播。尤度/遷移を真の `tvt` で直接学習。
  - **残差学習の強化**: PF出力（各scaleの pred＋事後分散/ESS/log_lik 等の不確実性特徴）を入力に、真値との残差を学習（既存 apply_pp の発展。**一番手堅い**）。
  - **NNが選ぶ/混ぜる**: 複数PF・複数scaleの出力を、坑井特徴で重み付けブレンド（選択は死んだが“連続ブレンド”は別物）。
  - **構造priorをNNで**: 近傍坑井・MD進行度から期待 geo_z を出すNNを **baseline/transition prior** に（kriging路線とも合流）。
- → 「NN×PF」は #6 として一括で論外にせず、**“残差学習＋不確実性特徴”と“微分可能PF”を別案として温存**する。
