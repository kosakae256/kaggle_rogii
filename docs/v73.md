# v73 — PF×機械学習(部分置換)設計 (2026-07-20)

## 目的・成功条件(ユーザー指定)
- **PF全体を置き換えるのではなく、一部をMLで置換**して精度向上。
- ベース: **r0_seed32**(`v65/warmup_v65.R0_PARAMS` = 錨なし正準PF)。**smooth lag=16 の平滑PF**を土台にするのが望ましい。
- **「逐次的に推論して補正していく」形式**が最も精度を上げられる、というユーザー直感を中心に据える。
- 成功条件: **CV(overall pooled) < 6.0 なら良い結果**。評価は単体(blendでない)を基本に。

## 土台(実在の資産)

  実測: r0 lag16 単体 **9.12** → `w *= exp(W_NN·sim)` (W=0.02) で **7.44**(全7バンクで改善=v51実証)。
  sim = v50 capaug fold-OOFエンコーダの cosine 類似(行×struct±45ft帯, `sim_rows_v51.pkl` キャッシュ有)。
- `v65/pf_engine_v65.py::_pf_core`: 部品が読みやすい正準エンジン(下の解剖はこれ基準)。

## 採用4コンポーネント(段階導入・全てトグル可能)

### C1: 学習emission(v51再現→強化)
`w *= lk_gauss · exp(W_NN · sim(particle位置))`。まず v51 資産(sim_rows_v51.pkl)で **7.44 を再現=v73の床**。
強化: 対照学習を「真位置 vs おとり(±1サイクル)」のランキングに特化 / 入力にマルチスケールGR窓。

### C2: 逐次オンライン補正器(★ユーザー直感の実装=本命の新規)
**PFと並走する小さなGRU観測器**。毎ステップ、innovation特徴
(事後平均位置でのGR残差 / 事後std / ESS / rate vs 初期dip / 尤度プロファイルの2峰性 / (C4)struct残差)
を読み、**粒子雲への微小補正(位置バイアス b_t と rateナッジ)を出力**して cloud に加える(=学習フィードバック制御)。
- **狙い**: 診断E([[formulation-diag-segment]])の**ドリフト46%は系統誤差**であり「特徴回帰では予測不能(診断D corr0.05)だが逐次再推定では直る」領域。まさに逐次補正器の守備範囲。
- **lag協調**: 平滑L=16と同じく、補正も「+L行先までのinnovationを見てから t−L を確定」する遅延適用にできる(未来証拠で補正=smootherと同じ合法look-ahead)。
- **学習法**: BPTT-through-resampling はやらない(v40教訓=微分可能化は縮退)。**凍結PFのロールアウトから innovation系列→現在誤差(真−事後平均) を教師あり学習 → 小ゲインで閉ループ適用 → ロールアウト再収集(DAgger式反復)**。
- 危険と対策: 補正器が「井戸を覚える」過学習 → fold-OOF学習(下記) + ゲイン小さく + 補正量にclip。

### C3: 曖昧度ゲート(適応温度)
行レベルNN(または軽いGBM)が曖昧度 q_t を出し、尤度温度を変調: `lk^(τ(q_t))`。
曖昧(2峰同点)→ τ小=平坦化=**自動hedge**(error_anatomy§4 posterior-mean原則) / 明瞭→ τ大=先鋭化=commit。
v66「σの解像度が全て」をrow方向に展開。C2の入力(2峰性)と共有可。

### C4: 証拠チャネル拡張(self/nbr/struct を soft に)
C1のemission NN入力へ self/nbr 疑似typewell照合とstruct場(v66_leanv1cumul)の残差を**特徴として**追加(乗算錨にしない)。
struct はCV水増しレバー([[v69-tabular-tcn-4bank]])なので **field-out CV で転移チェックしてから採用**。

## 学習・検証プロトコル
- **PF側は無改造トグル**: 各コンポーネントを on/off できる形で `_core` を拡張(v51スタイル)。A/Bは**同一seed同一chunk**で。
- **NNは5-fold(坑井GroupKFold)のfold-OOF**で学習・適用(v50/v51と同じ流儀=リーク無しCV)。
- **struct入り(C4)は leave-field-out も測る**(v68教訓: fieldリークが転移壁を隠す)。
- 報告は**別seed**で(v38教訓)。マジックナンバー(W_NN, ゲイン, τ範囲)は train-OOF 実証のみ([[overfit-policy]])。
- 評価: overall pooled RMSE(全773井)。**md_since帯別RMSE**も見る(C2がドリフトを削れているかの直接指標)。

## ★方針(2026-07-20 ユーザー確定): 処理順の逐次ML置換
**PF(r0_seed32, smooth lag16, n_seeds=32 固定)の各処理を a→f の順に一つずつML(NN/CNN等)に置き換え、
その段を限界まで詰めてから次の段へ**。改善は「方法・モデルの見直し」から始め、一つの方法に固執しない。
struct/self は積極活用(おそらく鍵)。**nbrは近接坑井にのみ意味がある**(距離ゲート必須、積制約は毒=C4実証)。
