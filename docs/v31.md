# v31 — マルチ参照 cross-attention アライナー(PF完全不使用の推論, feasibility probe)

> **状態: 実装済(未実行)。** ファイル: `v31/train_aligner_v31.ipynb`(生成: scratchpad/build_v31.py)。
> **判定基準(ユーザー設定): OOF overall RMSE < 10 が出なければ採用の余地なし**(PFフリー tabular の床 ≈13)。

## 仮説
- 現パイプラインは PF に強く依存(PF精度向上が前提)。一方、効いた**情報源**は PF 固有でなく
  「近傍井の共通性(v27 nbr)」「自分の既知帯(prefix, v29b d_prefix)」だった。
- 参照(typewell / 近傍井GR / 自分の既知帯GR)は**すべて共通 TVT 軸に載せられる** →
  照合エンジンを PF から **cross-attention** に置き換えられる。
  attention softmax = 各行の「TVT 上の位置」の事後分布 → **事後平均が出力**(双峰は2山に割れて自動 hedge = error_anatomy §4)。

## 方法(train_aligner_v31.ipynb)
1. **参照キャッシュ**(cell2, 初回のみ): 井戸ごとに TVT グリッド(typewell範囲±20ft, 0.5ft刻み)を張り、
   typewell GR / XY近傍≤5本(MAX_DIST1500, v28 neighbors_of と同機構)の全行(TVT,GR) / 自分の既知帯(TVT_input,GR) をビン集約。
2. **参照チャネル7**: tw_n / self_n / self_cov / nbr_mean_n / nbr_std / nbr_cov / tvt_rel(−lk)。GRは曲線ごと robust 正規化。
   **クエリ4**: gr_n / dgr / z_rel / md_since(局所窓は conv エンコーダが吸収)+ PrefixEnc 文脈ベクトル。
3. **モデル**: Enc1D(query)×Enc1D(ref) → 内積 attention → softmax(G) = TVT事後分布 →
   事後平均 + (std/entropy/pmax + query縮約) を入力とする軽い **RefineTCN** で最終値。
4. **損失**: ソフトターゲットCE(真値TVT周り N(y,2ft) をグリッド離散化)+ 事後平均MSE + final MSE。
5. 学習: GroupKFold(5)=v28/v29と同一fold、2seed、40epoch、flip TTA、EMA、bf16。**PF由来の入力ゼロ**。
6. 評価: OOF overall / wells>10 / **nbrあり・なし井戸の内訳**(近傍情報の寄与を直接確認)。
