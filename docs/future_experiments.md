## 4. typewellからの合成井戸(NN向け・高天井)
- dip経路をOUでサンプル→typewellからGR読み出し→較正+ノイズ、で**真値付き合成井戸を無限生成**。
- **ノイズはダイヤル**: ①ノイズ0(理想世界=カリキュラム初級)→ ②実井戸残差の自己相関ノイズ(~20ft)
  → ③**周期区間を選んで±バンドルのおとりを意図的に作る=双峰datum問題の教師を無限製造**(最重要の使い道。
  実データでは硬い核~30本しかない状況を数千本見せられる)。
- 用途は NN(ランカー/TCN)の**事前学習→実データfinetune**。シミュに無い落とし穴(較正ドリフト・tw不適合)への
  過学習に注意(混合比を振る)。生成自体はPF不要で数分。
- GBM行にするには合成井戸へのPF実行が必要(=マルチカットと同等のコスト)なので、まずNN用。
