# v103 — v100 に「emission なしの脱相関新バンク(dec10 + tw-affine)」を追加

## 仮説
v100(15バンク, LB 5.458 歴代ベスト)を超えるには **脱相関の新候補**が要る([[l5x-candidate]] 伸ばすのは脱相関新バンクのみ)。
v102 で **emission を全バンクに掛けたら L5 が回帰**した(候補多様性 −32〜45%)= **emission は「単体精度↑・多様性↓」で L5(bagging型)に有害**。
→ **dec10 と tw-affine を emission OFF で足せば、多様性を保った脱相関候補になり L5 が伸びる**はず。

## 変更点(v100 から)
- **v100 の 15バンクはそのまま**(v100 combo を流用、再生成しない)。
- **+ dec10(1バンク)**: 専用チューニング config(mult系)を **affine較正 + MD-10間引き**の併用、**5表現**、full平滑、**emission OFF**。→ 16バンク目。
- **+ tw-affine(15バンク × tw)**: v100 の全15バンクの tw表現に affine較正、full平滑、**emission OFF**。
- **結合はファイル化しない**: dec10/affine を **v100 と id整列の pf-only parquet** で出力し、**学習時に seqfeat が SF_EXTRA で結合**(巨大 train_combo を作らない)。

## 手法の概要
- 生成: `v103/gen_v103.py`(= create)。engine = `v102/build_forward_v102.py`(lean, create非経由)。MODE=affine_dec10(併用)/ affine。
  - 出力: `artifacts_v103/fwd/{dec10, aff_v96, aff_v97, aff_pf5}.parquet`(id/well + dec_/aff96_/aff97_/affpf5_ 候補列)。
- 学習: `v103/train_v103.py`。seqfeat(SF_IN=v100 combo, SF_EXTRA=v103 4parquet)で K≈91 候補 → L5(5seed)。TCN は SKIP_TCN=0 で追加。
  - `build_seqfeat_v97.py` に **SF_EXTRA**(追加parquetからid整列で候補結合)を実装。
- 提出: `v103/submit_v103.ipynb`(v100 参考。test で 15バンク + dec10/affine を生成 → 結合 → L5/TCN 推論)。

## 結果
- v100 基準: **L5 5seed OOF = 5.6684 / blend CV 5.5871 / LB 5.458**。
- **v103 L5(決定版 GroupKFold, 5model-seed)**:
  - dec10のみ = **5.5660**(v100 −0.102)/ dec10+tw-affine(all)= **5.5549(v100 −0.114)**。★脱相関新バンクが効いた。
- **即席 blend(v100-TCN + v103-L5all)= 5.4956**(v100 blend 5.5871 −0.091)。
- **★分割運の実測(seeded GroupKFold, group seed 振り)**: K=5 で det=5.5549 / g0=5.6582 / g1=5.6637 / g2=5.5707。
  **分割で ~0.09 ばらつく**。det の 5.5549 は"運の良い分割"寄り。**真の実力(平均)≈ 5.61**。cross-group アンサンブル(4構成)=5.5752。
  → **同一分割の差 −0.114 は本物**だが、**絶対CVは ~5.61 が正直**。単一固定分割の使い回しは ~0.09 のブレを固定していた。

## 所感
- **今日の核心**: emission は「単体精度↑・多様性↓」で **L5(bagging型)を悪化**させる(v102 emission全=回帰)。
  **emission OFF の脱相関バンク(dec10=affine+間引き, tw-affine)は多様性を保ち L5 を伸ばす** → −0.114。
- dec10 は間引きで軽い。**次の脱相関バンク候補 = anchor-free dec10**(`v65/artifacts_v65/v65pdec10_{jumpy_explorer,sharp_matcher,smooth_tracker}.json`, use_anchor=False。単体は弱い9-10だが錨に寄せない=最も多様)。
- TCN: ~4min/fold・5seed ~1.7h。**X_FP16=1 + V98_DA=0 必須**(でないと float32全表18.3GB→RAM thrashing)。train_nn は SF_EXTRA/EXTRA_FEATS で v103特徴に対応済み。
- 提出は **cross-group アンサンブル(全grid分割平均)**推奨(単一運分割より堅い)。submit_v103.ipynb + v103_submit_dataset 構築済(GRフリー錨=FOLD_ART→test展開で使用)。
