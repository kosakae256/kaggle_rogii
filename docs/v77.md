# v77 — 区間格子探索の深堀り: K16物理錨prior × 格子復号 × (NN拡張)

## 背景と狙い(ユーザー方針 2026-07-21)
- **足りないのは「数学的に異なる第2の推定器」**(STRIDE 1.3: 低ρブレンド。v76で脱相関ρ0.366は実証済み、単体水準27.5だけが壁)。
- v76バックボーンの敗因=datum錨の弱さ(S0+d0·md の素朴外挿)と目的関数の較正不足。**そこにK16物理錨をpriorとして注入する**。
- うまくいかない場合は「モデル(器)が違う」と判断して器を替える。NN・決定的アルゴリズム版も歓迎。

## 使う物理錨: `検証/rogii_k16_spline_kernel_knn_adaptive_kappa_2.py`
- **GR不使用の純幾何モデル**: TVT(row) = 錨TVT + cumsum( κ(dd)·( −dZ + D̂·cos(az−θ0) ) )。
  D̂=近傍train lateralのドリフト場のガウスkNN(k15, h500ft) / κ=ドナー距離binごとに buffered-LOO で結合最小二乗フィット / 方位ゲート。
- **転移設計が誠実**: κ(dd)が距離で自己減衰(遠いドナー=弱く効く)、検証は「場・κともtrainのみ・valid/test完全部外者」3分割
  (`検証/holdout_eval_kappa2.py` ほか)=隠しtest同条件。LOO pooled 9.67ft(@~500ft donors)/11.53ft(@≥1500ft)。
- v38/v66 structとの違い: 同じK16幾何が源流だが、**行レベル尤度錨として使わず**、σ(dd)付きの区間priorとして使う。
  禁止対象(v38 prior pkl/v66場)は不使用。※それでもcross-well空間情報なので **space-block(leave-field-out)ゲートを昇格必須条件**にする。

## 計画(優先順)
### P1: K16錨priorの注入(非NN, 本命)
- 前計算: 各坑井の錨軌跡 A(row)=K16予測TVT+Z(=S空間) と σ(row)=f(dd)(ドナー距離から。LOO残差でσ(dd)カーブ較正)。
- バックボーンのdatum priorを置換: 区間端で pen = W·((S_end − A(end))/σ(end))²。現行の素朴prior(S0+d0·md, σ=12+0.008·row)より
  中心が賢く、σが「外挿の正直な自己申告」になる。**離散区間prior形なので誤差構造法則(連続引き=井戸定常バイアス毒)に抵触しない**。
- 掃引: W_ANC×σスケール。60→200井。**K16単体(9.7-11.5)より格子復号(GR証拠込み)が上回るか**が最初の関門。
### P2: 目的関数の較正(v76の壁の正面突破)
- 長さprior: 真面の区分線形統計から実データfit(v76 D6の拡張)。
- 井戸別尤度正規化: 尤度分離度(真vs帯)の井戸差を温度で吸収(弱コントラスト井戸でprior優位に自動調整)。
- consensus checkpoint(STRIDE 1.1): 中間点でビーム変種を照合しdatum投票→リセット。
### P3: 決定的アルゴリズム版(「PFのように決まった手順で動く」器)
- ビーム(貪欲・確率なし)の代わりに **(S格子×dip格子)のexact forward-backward sum-product**(doc1のtrellis形:
  50ft節点・Cauchyコスト・dip persistence・K16 datum prior)。**posterior mean出力=固定アルゴリズム・乱数なし**。
- ビームとDPの両輪で「探索の失敗」と「目的関数の失敗」を切り分けられる。
### P4: NN拡張(実証済みの形のみ)
- **doc1実証形**: 小さな学習emission補正(19kパラ級)を**古典コストに小weightで加算、復号は古典のまま**
  (彼: weight0.005で blend 7.699→7.623)。学習はfold-OOF。
- 教訓遵守: オフライン指標(val ranking等)では判定しない。**判定は常に復号A/B**(v76/selfch教訓)。
- (P4b, 任意) NN区間提案: ΔS候補格子をNNで坑井適応化。P1-P3が水準到達後のみ。
