# v87 — v69_4 の PF に「affine較正版」15本を追加して tabular 学習

## 仮説
GR の自己相似性(Milankovitch cyclicity)で PF が追いにくい。**GR表現を affine 較正**
(観測hw GR を参照typewell/self/nbr grid の振幅・オフセットに合わせて α,β 再較正)すると、
同じ PF パラメータでも別の枝を拾い、**非affineと脱相関した候補**になる([[v85-gr-representation-ensemble]] で
affine は raw と ρ0.634 と最も脱相関、logamp は ρ0.89 で冗長、と実測済)。
その affine 候補を **v69_4 の tabular(GBM選択器)に食わせれば**、選択で拾えるか、を試す。

## 変更点(v69_4 → v87)
- **PF は v69_4 の 5バンク(p_1..p_5, struct-free, use_anchor=False)をそのまま流用**。パラメータ変更なし。
- **affine 較正版を15本追加**: 5バンク × {tw / self / nbr}。
  - **self, neighbor は self/neighbor 疑似typewell を作った"後"に affine**(観測 GR を参照 grid へ α,β 再較正)。
  - α は [0.3, 3.0] にクリップ。gs(尤度σ)は aligned スケールで再計算(build_smoother_inputs と同手順)。
- **「self/nbr/affine の違い(共通点)」を特徴量化**(ユーザー指示):
  - affine効果: `pf_afftw_vs_tw`, `pf_affself_vs_self`, `pf_affnbr_vs_nbr`(affineで予測がどれだけ動いたか)
  - affine 3源の食い違い/一致: `pf_afftw_vs_affself`, `..._vs_affnbr`, `pf_affself_vs_affnbr`, `pf_aff_agree_std/range`
  - param跨ぎ集約: `pf_afftw_mean/med/std_between`(源別), `pf_aff_all_mean/med/std_between/range_between`(15本全部)
  - affine係数(坑井レベル定数, prefix由来): `aff_a_{tw,self,nbr}`, `aff_b_{tw,self,nbr}`(param平均)
  - **計 108 affine列**。
- **転用**: v9特徴・非affine PF(pf_ancc/self/nbr_1..5)は v69_4 train.parquet を**再計算せず流用**。
  非affine tw/self/nbr は `pfpass_cache_v69.npz` から読み(diff特徴用)、affine 15本だけ新規に回す。
- **SMOOTH_LAG=16**: v69_4 基底parquet/submit は lag16 運用と**実測確認**(1井の非affine tw PF を lag16 で再計算し
  cache と mean|diff|0.26≈GPU非決定性、lag192 は 0.99/max7.1 で明確に別物 → 基底=16 確定。doc「本番192」は未実行)。
  affine も 16 で揃える(diff特徴の train/test 整合のため必須)。
- **v69_4 のフルパイプライン(tabular GBM → 系列NN TCN → 残差ブレンド)を踏襲**。affine は GBM/NN 両方に投入。
  - train_nn の FORCE_PATTERNS に affine を追加(候補15+affine効果15+一致度+集約+係数=**78/108列を強制投入**、
    残り30=per-bank std/delta は importance 経由)。NN幅 TOP_K=192(v69_4踏襲。affineが~40%を占める=フェアな検証)。
  - submit は **submit_nn(GBM×NN残差ブレンド)**。build_dataset 直後に affine 15本を計算し test_df に id merge。
  gf(v48 grid filter)は v69_4 の既存特徴なので踏襲(struct を soft prior で使うが v87 が新規に struct を足すわけではない)。

## 設計上の要点 / 落とし穴
- **affine の適用場所**: 観測 hw GR を `(GR−β)/α` で参照 grid スケールへ寄せる(grid は不変)。
  self は参照 grid が自分の prefix GR 由来なので **α≈1(実測 aff_a_self≈0.998)**。それでも gs再計算で予測は動く
  (self grid≈自GR → 残差縮小 → gs が下限に張り付き**過信**気味。[[v65-composite-likelihood-pf]] の「self β1過信」と同根)。
  nbr は近傍井 GR 由来で **α が井戸により振れる(aff_a_nbr std≈0.18)**=較正が実質的に効く。
- **id 結合**: parquet は `id={wid}_{eval行index}`。affine parquet も同 id。行順一致なら positional、
  ずれれば reindex(train cell に両対応を実装)。
- **diff特徴の train/test 整合**: 非affine は train=cache / test=_FWD_ENS だが**両方 batched・lag16**なので整合。

## 判断ポイント(本学習=ユーザー実行)
- **CV(OOF overall RMSE) が v69_4 の GBM単体 / GBM×NNブレンド を上回るか**。affine候補+違い特徴が「datum両義の枝判別」に効くか。
- tabular(GBM) と NN(TCN) の両方で affine importance/貢献を見る。NN は affine を78列強制投入している。
- [[v85-gr-representation-ensemble]] の教訓: affine blend の CV利得は**強いエンジンで縮み、LB転移も弱かった**
  (弱PF上の現象)。今回は blend でなく **GBM特徴化**なので、選択器が拾えれば転移しうる。ただし過度な期待はしない。
- affine単体候補(afftw/affself/affnbr)は非affineより弱い可能性大。**価値は違い特徴(脱相関シグナル)にある**想定。
