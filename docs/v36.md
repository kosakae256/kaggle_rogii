# v36 — 逆方向データ増強(backward DA)

> **状態: 実装済(未実行)。** ファイル: `v36/create_train_backward_v36.py` → `v36/train_models_v36.ipynb`。
> 背景: ユーザー観測「ROW_FRACを下げると精度低下」= **データ量が律速**。行を増やす増強の第1弾。

## 仮説
逆方向(toe→heel)に解いた合成タスクは、smooth/forwardとも既存9パスとも違う癖のデータになり、
単なる行の水増しでなく「別の見え方の教師」を追加できる。GBMの精度はデータ量に感応する
(frac実験)ので、行数≈2倍弱の増強はCVを押し上げるはず。

## 設計
### 生成(`create_train_backward_v36.py`)— 逆方向のみ実行(順方向は既存を流用)
- **CSVレベルで井戸を反転**(行順反転 + MD' = MDmax−MD)して、**既存の v28 create パイプラインに
  そのまま通す**(`C.DATA_DIR_V26` を反転CSVディレクトリに向けるだけ)。md_since / PFアンカー(ls, ir) /
  beam / NCC / self grid 等の全特徴が鏡像世界で自動的に整合し、特徴ごとの手動反転が不要。
- **反転CSVは元のevalゾーンの行だけで構成**(★元の既知帯は予測対象にしない=ユーザー指示。
  既知帯行を末尾に残すとPFのprefix前提が壊れるためCSVごと除外)。
- 疑似既知帯 = toe側の実区間 K 行(TVT_input := 真値TVT)。K = min(元既知帯長, n_ev/2)、下限30。
  **逆方向の行数 = n_ev − K**(事前区間の分減る)。n_ev−K<50 はskip。
- 近傍(nbr)参照は他井戸の (GR,TVT) ペア集合なので行順反転の影響なし(binning順序不変)。
- 出力: `v36/artifacts_v36/data/train_backward.parquet`(`is_backward=1` 列付き)。
  順方向のparquetには一切触らない。計算量 = v28 create 1回分(9本smooth PF、GPU数時間級)。

### 学習(`train_models_v36.ipynb`, v35メモリ効率版ベース)
- 順方向 = `v36/artifacts_v36/data/train.parquet`(v28本家のコピー、ユーザー配置)+ 逆方向を concat。
- **train = 順+逆 / 検証・OOF評価 = 順方向行のみ**(本番タスクと同じ分布で測る)。
  foldは井戸単位GroupKFold — 逆行は同じ井戸名なので同じfold側に落ち、**リークなし**。
- `is_backward` を特徴に追加。**submit側は既存の「features.jsonにあって無い列は0埋め」ロジックが
  そのまま順方向=0として機能**するので提出ノートの改修不要。
- **USE_BACKWARD トグル**で ablation(False=順のみ基準)。fold pklは models_bwd / models_fwd に分離。
- frac=1.0・pyarrow列チャンクロード(X 1枚だけ保持)。concat時 X ≈ 5-6GB 見込み。

## 判定
- USE_BACKWARD=True vs False の同一fold比較(検証行は同一なので直接比較可)。
- 基準(全行): v28本家 GBM単体+pp 7.0481 / blend 6.8711。
- 注意: 逆方向タスクは疑似既知帯が実既知帯より情報量が少ない(短い)ので難しめのタスク。
  train行としての価値はそれで良い(難しい教師)が、逆行の学習lossが高くても気にしない。

## 提出実装(2026-07-07, ユーザー指示で tabular 単体に変更)
`v36/submit_v36.ipynb`(生成: scratchpad/build_submit_v36b.py, **submit_v29bベースからNN/ゲート/geoを全排除**):
- チェーン = **9GBM(v36, models_bwd) → apply_pp → SG のみ**。v28の6.026チェーンとGBM以外同一
  = **逆方向DAのLB効果を単変数で読むA/B**(6.026との差がそのままDAの効き)。
- **test側は逆方向を生成しない**(逆行はtrain増強専用)。`is_backward` は既存の「無い列は0埋め」で順方向=0。
- 必要 input: comp + **rogii-v36-artifacts(features.json / pp_params.json / models_bwd)** のみ。
- SGを外したい場合は cell2 の SG_W=0。

## 結果(2026-07-07)
- CV(OOF, 順方向評価): 逆方向DAで **−0.05** の改善。
- **★★★LB 5.864 = 新ベスト**(v28同一チェーン6.026から**−0.162**。gate入りフルチェーン5.930も超えた)。
- **CV−0.05 → LB−0.162 の増幅転移(×3以上)**: 転移率の階段(PF系70-100%/tabular系40%/後処理~10%)の
  さらに上を行く初のケース。解釈: DAの効果は「train井戸への当てはまり」でなく「モデルの頑健化」なので、
  train-OOF(既知フィールド・データ豊富)では見えにくく、**隠しtest(未知フィールド)でこそ本領を発揮**する。
  ユーザー考察のとおり「逆方向を足すと堅牢になる」がLBで実証された。
- 事前の期待値(転移40%則で≈6.00)は大外れ(良い方に)。**増強系はCVのΔを過小評価として扱うべき**という
  新しい換算則がここで得られた。
