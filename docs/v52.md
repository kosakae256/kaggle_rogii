## 仮説
v47 TCN(OOF 6.411 = CV最良)は「PFバンク→特徴→TCN」の鎖。土台のPFを NN-emission で一斉底上げ
(r0: 8.75→7.44 等)し、さらに3エンジン(r0+NN / pfA+NN / v50B)の特徴を加えれば CV 5.x に届くはず。

## 変更点(v47 から)
1. **バンク = 6本**(pf_1/2/3, r0, r1, pfA)— r4 除外。smooth lag16, **seeds 32**。
2. **全バンクに NN-emission**: `w *= lk_raw × exp(W·sim)`、**W=0.02(pfAのみ0.01)**。
   sim = v50 capaug エンコーダ(train=OOF pkl / test=5本平均で自己生成)。
3. **v50B(学習デコーダ)特徴 4列**: v50b_delta / v50b_std / v50b_margin(枝確信度) / v50b_maxp。
4. gf 3列は v47 と同様に継続。

## 実装メモ
- create = v47 create のコピー+検証付き14パッチ(6バンク/NN-emission/パス)。3坑井スモーク通過(722列)。
- NN-emission の機構: `_prepare_sims`(train=sim_rows_train.pkl / test=nn50/エンコーダ5本平均)→
  `_v26_pad` が stq/simt を添付 → core が粒子位置で sim を gather し `lka *= exp(w_nn·sv)`。
- submit: エンジンcellに同じ13パッチ+v50Bセル(エンコーダsim→10ch証拠→combo デコーダ5本平均→4特徴)。
  チェーン = 9GBM平均残差 × TCN残差(w=OOF最適)→ apply_pp のみ(SGなし)。
- artifacts_v52 同梱: nn50/(capaugエンコーダ5+comboデコーダ5)、struct_field_v38.npz、
  sim_rows_train.pkl(train専用・Kaggle不要)。
- v50b test 特徴の γ用 simスケールは定数 11.3(capaug 学習時スケールの近似)。

## 結果
- **GBM(tabular)OOF = 6.27(raw)/ pp 6.279(2026-07-11 ユーザー実行)** — v47 同段 **6.70(pp CV)** から **−0.42**。
  NN-emission バンク+v50b特徴の底上げがそのまま転写。
- **TCN(combo)単体 pp = 6.147 / blend(w_nn=0.68)= 6.1115(2026-07-11)= ★CV歴代最良更新**(旧 v47 6.411 → −0.30)。
  >10ft井戸 63→55 と tail も改善。TCNの上乗せは v47 の −0.29(6.70→6.411)→ −0.17(6.28→6.11)に縮小
  (GBM が v50b/gf と強バンクを吸収済みでNNの限界効用が低下。w_nn 0.8→0.68)。
  ※学習ログの「v47 GBM単体 6.2791」表記はコピー元ラベルの残骸で、実体は v52 GBM の pp 値。
- **pp再調整(2026-07-11)**: (w_nn, w_pf, τ, α) を OOF 粗グリッドで同時再導出 →
  **(0.60, 0.05, 40, 1.03)で blend 6.1115 → 6.0825(−0.029)= CV 6.0台到達**。
  旧値(0.09/85/1.0)は旧世代 pf_ancc 向けの化石だった。pp_params.json と submit の W_NN_OVERRIDE に反映済み。
- **LB(tabular単体)= 6.352(2026-07-11)**: CV 6.28 → 転移率 ≈1.01。v47 tabular(6.700)から −0.35。
- **LB(blend)= 6.350(2026-07-11)**: CV 6.083 → 転移率 1.044。見込み(6.10〜6.15)を下回り、
  **tabular単体(6.352)と実質同値(−0.002)= TCNブレンドの CV−0.20 が LB でほぼ消失**。
  - v47 では TCN 上乗せ(CV−0.295)がフル転移(6.700→6.405)したのと対照的。解釈:
    **土台(GBM)が強くなるほど NN の残り取り分が tail/hard 井戸に偏り、隠しtestのtail希薄構成
    (v39 で実証済)で上乗せが薄まる**。NNブレンド自体の逆噴射ではない(LB非逆行)。
  - CV優先方針([cv_lb_policy.md](cv_lb_policy.md))により blend は採用継続(PBではCV差が効く想定)。
  - 含意: LB を動かすには median 井戸を動かすレバー(逆方向DA=v36系、候補生成の質=v53)が必要。
