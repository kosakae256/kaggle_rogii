# v90 — 逐次推定(PF)の進化: 非逐次(U-Net/SDF)の知見を注入

## 背景 / 動機
v89で得た核心知見を PF(逐次) に転用する。
- **脱相関はアーキ由来**(早期枝コミット vs 全体読み)。PFの弱点＝早い段階で枝を1つに畳み誤差が相関する。
- **非逐次のδ分布は双峰で top-2 に真枝が69.6%**(oracle 7.04)。＝両枝候補を明示的に保持できる。
- **SDFの変位投票**＝各セルが真δへの変位を出すHough的読み出し(smootherが欲しい素)。
- **錨に焼くと脱相関が死ぬ**([[v41-anchored-pf-tabular]])→ 焼き込まず「提案分布/事前」の形で融合する。
- 実測資産: 非逐次脚 vs r0 ρ0.34 / blend 8.05、SDF置換 11.81、r0(struct-free) overall 8.72。

## ★本命(v90.0): 非逐次δ分布を PFの per-step 事前に注入(両枝シード維持)
### 仮説
PFの粒子重みに、非逐次モデルのδ分布(双峰)を各粒子位置で評価した項を掛ける。両枝の粒子が
リサンプリングで生き残り、逐次の滑らかさ(dip連続)が正しい枝を選ぶ。焼き込まないので脱相関blendの利得も残る。
### 手法
- `pf_engine_v65._pf_core` の重み更新 `w*lk*lkp*lka` に **lkn=P_ns(bin(i), δ=粒子TVT−ns中心)^β** を追加(v65本体は無改造、v90にコア複製)。
- P_ns = v89 の δ分布(SAVE_DIST保存, softmax boot 由来)。bin単位(nb×ND)で保持しrow→binはbidで写像→軽量。
- ns中心 = learned pkl の st(boot中心)。粒子TVT v=pos−z を δ=v−st[i] に変換し offs 格子で内挿。
- β は小(0.05〜0.3)で走査。struct/PF錨(use_anchor)は off のまま(r0基準)。
### 検証条件
- fold0 val坑井で **r0(8.03) と同fold比較**(overall プール)。dist_f0 があるfold0で PoC。
- 判定: guided PF < r0 なら成功。加えて guided×r0, guided×非逐次 の相関/ blend も見る。
- 効けば全fold分の dist を出して全773で確定。

## 結果 (2026-07-25)
### v90.0 初期: per-step guidance は単調に悪化(NW=20 fold0)
- BETA走査: 0→7.01 / 0.1→7.36 / 0.25→7.53 / 0.5→7.74。**βを上げるほど悪化**。
- 解釈: **PF(8.03)は非逐次(11.8)より強い推定器**。弱い方のモードへ粒子を毎ステップ引くと劣化。
  脱相関はblend(8.05)で使うのが正解で、per-step注入は弱信号でPFを汚す。alignment/BETA=0対照は健全。
- 次の検証: 非逐次の価値は**PFが外す硬い坑井**にあるはず。硬/易で分けてguidanceが硬い坑井だけ効くか(全fold0でBETA0 vs0.3 per-well比較)。効けば「硬い坑井限定guided PF」へ。

### ★硬/易分割の発見: 答え注入は"硬い坑井を救う"(要ゲート)
- BETA=0.3 per-well(fold0 155井): 易(r0≤10,130井)4.81→8.33(悪化) / **硬(r0>10,25井)16.03→10.59(−5.4ft, 23/25改善)**。
- ⇒ ①の狙い(硬い枝を非逐次で救う)は正しい。易しい坑井を引くのでoverallは負ける。**硬い坑井ゲートで tail 救済**の筋(別途)。
### ★方針転換: 表現(emission)をPF尤度へ = v90.1(ユーザー指摘=本筋)
- 学習emission(capaug, EVのc_learn)は"尤度"→毎ステップ掛けてよい(Bayes更新として正しい)。v90.0の事後注入は二重カウントの誤り。
- 期待: 易しい坑井は生GRと一致(無害)、硬い坑井はゴースト抑制(有益)。GRID=emission で c_learn を尤度に乗算。

### ★★v90.1 emission尤度: 微小Wで大改善(NW=20 fold0 速報)
- GRID=emission BETA走査: 0(対照)7.01 / **0.02→5.20(−1.8ft!)** / 0.05→7.07 / 0.1→9.71 / 0.3→9.39。
- **微小重み(W≈0.02)が最適**(v51のW≈0.02, −1.22と整合)。機構=ゴースト抑制で枝を正す。leak無(fold0 OOF enc/center)。
- 全fold0(155)で確認必須(対照BETA0=8.13)。確定なら「PFのGR表現を学習emissionに」が本線。

### ★★★v90.1 emission尤度 全773井 確定 (2026-07-26)
- **全773: BETA=0(対照)8.75 → BETA=0.01 7.67(−1.08ft)**。fold0(−0.87)より大=全foldで一般化。
- fold0 W微調整: 0.005→7.25 / 0.008→7.34 / 0.01→7.26 / 0.012→8.15 / 0.015→7.97。最適=0.005-0.01の鋭いピーク。
- 素PF 8.72 → 7.67 を「学習emission(capaug表現)をPF尤度に極小重み乗算」だけで達成。v51 r0+NN 7.445/v65 struct20 7.881 級。
- 機構: ゴースト抑制の学習表現が枝を正す。leak無(fold OOF enc/center)。**「PFのGR表現を学習emissionに」がv90本線**。
- 次: W最適(0.005-0.008)確定 / 全773でのr0との相関(脱相関脚か) / 硬い坑井ゲート(v90.0)との合わせ技 / SDF由来emissionでの比較。

### W最適(全773)は非単調=要ロバスト化 (2026-07-26)
- 全773: W0→8.75 / 0.005→7.60 / 0.008→8.05 / 0.01→7.67。**非単調(効果は本物だがW鋭敏)**。
- 全Wで8.75改善は確実だが最適Wが不安定=枝flip挙動が敏感。現実装(binned emission+δ窓中心)由来の可能性。
- ロバスト化案: 複数seed平均 / 中心フリーの生emission(推論時エンコーダで per-position 評価, δ窓依存を除去) / W小域の平滑化。
- 確定: emissionでr0 8.75→7.6〜7.7(−1.0〜1.15ft)は本物。最良W=0.005(7.60)。
