# v95 — 5参照マルチ表現バンク（v93再構築 / 逆方向・NN-emission 無し）

> v93 の create/train/submit パイプラインを土台に、**PF参照を3→5表現に拡張**し、
> **各表現の"利点"をモデルへ説明する特徴（GR尤度・信頼度変数）を追加**する版。作成 2026-07-30。
> 前提知見は [v93_summary.md](v93_summary.md)（v93全体像）を参照。

---

## 1. 仮説
- v93 は各PFバンクを **tw / self / nbr** の3表現で回し、その予測と相互不一致を特徴化して tabular/TCN/L5 に食わせていた。
- **今日の実験（v94期, 全773井）で、参照の"種類"を変えると誤差が脱相関することを実証**（同一PF・別シード, off params）:
  - 単体RMSE: tw 9.18 / self 9.34 / nbr 9.58 / nbr_gr5 9.46（tw が最良単体、他は超えない＝**別種参照は"より良い照合器"でなく脱相関特徴**）。
  - 相関ρ: nbr_gr5 が最脱相関（vs tw 0.48 / vs self 0.41）、self も脱相関（vs tw 0.50）。
  - **4参照 min-var blend 7.45**（≈振幅バンク）だが **per-well oracle 5.22 / per-row 4.19**（振幅バンク oracle 6.11 より大）＝**選択器（tabular/TCN/L5）が伸ばせる余地が大きい**。
  - **self_graft**（selfをprefix範囲外へ tw較正外挿）は単体は弱い（8.97）が **self と 0.42・全参照中で最も脱相関** ＝脱相関特徴として価値あり。
- ⇒ **仮説: tw/self/nbr に nbr_gr5・self_graft を足した5表現でバンクを回し、特徴化すれば、選択器が oracle 側の余地を取りに行ける。**
- 追加: **各表現がいつ効くかをモデルが学べるよう、表現ごとの GR尤度・信頼度変数を特徴に入れる**（例: nbr_gr5=選ばれた井のGR類似度、self=prefix被覆、self_graft=較正係数、nbr=距離/本数、各表現の予測位置でのGR残差）。

### 棄却した派生（今日の実験で確認）
- **nbr_gr1（GR類似top-1）**: 全773で 10.01（tw より悪い・最悪）。100井の優位はサブセットノイズ。top-1は分散大 → **≥5井のデノイズが効く**（採用は nbr_gr5）。
- **類似度空間バリエーション（band-pass/微分でnbr選択）**: raw選択と corr 0.94-0.99＝redundant。変換で参照を増やしても直交しない → 不採用。
- **近傍サーフェス（v69, ANCC面）**: train限定ANCC使用でtest不可、prefix面は転移せず（49.7ft） → 不採用。

## 2. 変更点（v93 → v95）
| 項目 | v93 | v95 |

| PF表現 | tw / self / nbr（3） | **tw / self / nbr / nbr_gr5 / self_graft（5）** |

| NN-emission | あり（w_nn=0.02, pfA=0.01, 帯中心=錨） | **無し（w_nn=0・sim非添付）。コアの `if w_nn>0` は温存＝後で再追加可** |

| 錨（物理prior） | GRフリー錨（attach_anchor, pfAのみ） | **同一（流用）** |

## 3. 手法の概要

### 3.1 5表現（各バンク共通。全て "参照GR-vs-TVT格子 gg の作り方" が違うだけ）
1. **tw** = 公式typewell（`build_smoother_inputs`）。
2. **self** = 自分の既知prefix GR(TVT_input) を tw格子に median substitute（`build_inputs_self`）。
3. **nbr** = XY重心距離<1500ft・最近傍≤3井の (GR,TVT) を substitute（`build_inputs_nbr` + `imputers.neighbors_of` 距離選択）。
4. **★nbr_gr5（新）** = **全train井から GR類似（targetのprefix層序に一致）top5** の (GR,TVT) を substitute。選択は tip（実prefix点）でGR相関（今日 raw選択=最も脱相関の版）。`build_inputs_nbr_gr5` + `imputers.neighbors_gr_of`。
5. **★self_graft（新）** = self（prefix実測）＋ **prefix範囲外を tw較正（self≈a·tw+b, a∈[0.2,5]）で外挿**（`build_inputs_self_graft`, v49 build_inputs_self_ext 由来）。

### 3.2 説明特徴（★"その特徴がどう作られたか＝妥当と説明できる変数"をモデルへ）
狙い: 各表現の予測 `pf_X` に対し、**それが信頼できるか/妥当かをモデルが判断できる provenance・信頼度変数**を併記する。
これにより tabular/TCN/L5 が「nbr_gr5 は一致度が高く近い井の時だけ信じる」等を学べる。

各バンク×各表現で:
- **(A) GR一致度（provenance の核）**: その表現の参照 gg が、この井の**既知prefix GR とどれだけ合うか**。
  `grfit = std(gr_prefix − gg(TVT_input_prefix))`（低=その参照がこの井のGRを良く説明＝妥当）。prefix限定＝valid・test可。
  さらに **prefix相関** `corr(gr_prefix, gg(prefix))` も。
- **(B) 表現ごとの由来変数**:
  - **nbr**: 使った近傍井への **距離 min/mean（XY）**、**|ΔZ| min/mean（深度差）**、本数、被覆率。
  - **nbr_gr5**: 選ばれた5井の **GR類似度 top1/mean**、それら井への **距離 min/mean・|ΔZ|**、被覆率。
  - **self**: prefix **被覆率**（selfが有効なTVTビンの割合）、prefix行数。
  - **self_graft**: **較正係数 a, b**、有効フラグ、外挿した割合。
  - **tw**: grfit（baselineの一致度）。
- **(C) 他表現との比較（相対的妥当性）**: `pf_X − pf_tw`（既存）、`pf_X − pf_(他)`、5表現の予測 spread/range/mean、
  **grfit の相対**（例: nbr_gr5 の grfit が tw より小さい＝nbrの方がこの井に合う、を示す差分）。
- **(D) PF由来の適合度**: run_smoother_ext が返す **loglik**（seed最良のper-row平均対数尤度＝その表現PFのGR適合の総合値）。

### 3.3 パイプライン（v93と同形）
- **create_v95.py**: 有効井列挙 → imputer構築 → 各バンク × 5表現 smooth-PF（GPU, lag16, n_seed32, **w_nn=0**）→ ENS格納 → features.build_well + build_self_nbr_columns（5表現＋説明特徴）→ train.parquet。
- **train**: L1 GBM（`train_l1_gbm_v95`）/ L2 TCN（`train_nn_v95`）/ L5 曲線トークン（`train_l456_v95`, build_seqfeat）。GroupKFold(5) 共通・決定的。top-k絞らない [[tcn-no-topk]]。
- **submit**: `submit_v95.ipynb`（forwardのみ, nnls blend GBM/TCN/L5）。逆方向・fwdbwd は無し。

## 4. ファイル計画（v93複製→改修, ART=artifacts_v95）
- `pf_banks_v95.py`: v93複製 + `build_inputs_nbr_gr5` / `build_inputs_self_graft` 追加。run_smoother_ext は **予測位置GR残差も返す拡張**（説明特徴用）。NN-emissionコアは温存（create側 w_nn=0）。
- `imputers_v95.py`: v93複製 + `neighbors_gr_of(prefix_gr, prefix_tvt, exclude_wid, k=5)`（GR類似top5, tip相関）。
- `features_v95.py`: build_self_nbr_columns を **5表現＋説明特徴** に拡張。NBR_GR5_ENS/SELF_GRAFT_ENS と信頼度メタを受ける。
- `create_v95.py`: 5表現ループ・w_nn=0・sim非添付・逆方向無し。
- `train_l1_gbm_v95.py` / `train_nn_v95.py` / `train_l456_v95.py`: v93複製・入出力パスをv95へ。
- `submit_v95.ipynb`: forward単独・nnls blend。
- config: `artifacts_v95/pf_banks_config.json`（v93からコピー＝同一PF param）、`grfree_anchor_train.pkl`（v93からコピー）。

## 6. 所感 / 留意
- **nn_emission/逆方向を外す＝v93最良(fwdbwd warm 6.0079)より一旦は落ちる可能性**。ただし土台を単純化し、5表現の脱相関で取り返す設計。NN-emission・逆方向は後から再追加できる形を保つ。
- **絶対値の注意**: 5表現の oracle(5.22)・blend(7.45)は "off params 単体PF" の値。本番は smooth6バンク × 5表現 × 選択器なので数値は変わる。**相対（脱相関・oracle余地）が採用根拠**。
- **転移リスク**: nbr_gr5 は "GR類似する遠い井"(中央5816ft) を参照＝同フィールドのtestでも一致井が train にある想定。leave-self-out・prefixのみ選択でリークなし・test適用可。ただし転移は本番LBで要確認。
- 恒常制約: **struct全面禁止**（[[no-struct-directive]]）/ CV信頼 / overall RMSE / RAM20GB・VRAM12GB / n_seeds下げない / ユーザーが書かせた学習コードは勝手に実行しない。
