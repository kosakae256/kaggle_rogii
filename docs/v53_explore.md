## ガードレール(過去事故の再発防止)
1. **OOFの徹底**: 学習済みモデル(decoder/encoder)を train 井戸に使うときは必ず自fold(OOF)のみ。
   5本平均は test 専用(2026-07-12 の ch28 リーク事故 = fold0 4.296 は偽物、修正後 5.047)。
2. **井戸指紋/検索系は禁止気味**: 井戸単位 CV はフィールド指紋の過学習を検出できない
   (v34 ランカー: in-sample 4.99 / OOF 6.75 / LB 7.28)。retrieval・well-embedding 系をやるなら leave-field-out で別途検証。
3. **評価は必ず同一プロトコル**: z = st + δ̂ を y_ev の有限行でプール RMSE。155井戸全部で(部分集合の良値は無意味)。
4. **良すぎる値(≤4.5)が出たら喜ぶ前にリーク監査**(train行の情報が入力に混じっていないか)。
5. 井戸レベル定数シフト系後処理は LB 非転移の前科(v32)— fold0 で勝っても採用注意の但し書きを付ける。
6. 1実験に時間をかけない。**小規模(小CH/サブセット)で当たりを見てから延長。**
7. **★known(プレフィックス)マスクの罠(2026-07-12 実地で発火)**: ch7(self有)の δ中心値は
   **評価binでも61%がON**(評価ゾーンのstructが既知TVT帯に重なるため)。これをknownマスクにして
   dtrue を特徴に使うと正解が漏れる(exp15初版: AUC0.958/3.837=偽物)。
   **正しいknown-bin = そのbinに評価行(y_ev有限)が1本も無い**: `~np.logical_or.at(has_ev, bid, isfinite(y_ev))`。
   dtrue を使う特徴は必ずこのマスクで(かつ井戸集約/prefix端のみ — per-binは評価binで常に0)。
8. **学習の作法(2026-07-12 ユーザー指示)**: epoch数に上限を付けず、**アーリーストップが基本**。
   **モデル選択は valid loss が最小のチェックポイント**(fold0 val の loss。RMSEでなく loss で選ぶ)。
   実装目安: 毎epoch val loss 計測 → best 更新で state 保存、patience≈15 で停止、
   LR は cosine でなく ReduceLROnPlateau(factor0.5, patience5)系。壁時計の安全上限(~45分)だけ持つ。

## アイデアキュー(「別のアプローチ」候補。上から潰す。結果に応じて追記)
1. **EvSeq**: δ軸を集約した per-bin 特徴ベクトル(各chの max/argmax/entropy/top2gap/struct近傍質量等)→
   TCN/GRU+MDN の**系列回帰**(v29b 家系を evidence 上で。分類場でなく回帰の定式化替え)。
2. **PathDecode**: 融合場(decC_f0 logits か EV の log和)上の **DP/ビーム経路復号**+遷移prior、
   top-B 経路の重み付き平均(soft)。学習不要で速い。v25 beam 家系の fused-field 版。
3. **ModeDP**: 各binの top-K モード抽出 → 時間方向の枝一貫性 DP → **soft枝事後で加重平均**(v34 softゲート家系)。
4. **ContOpt**: δ(t) を連続変数として -log(場) + 曲率罰の**エネルギー最小化**(Adam, モード多スタート)。学習不要。
5. **GhostPrior**: 場のδ自己相関からゴースト間隔(~±15ft)を井戸別推定 → モード統合/位相コヒーレンス罰。周期の明示モデル化(v47 の残り軸)。
6. **Coarse2Fine**: 粗い事後で経路を決め、±10ft 帯を切り出して**第2段の精密デコーダ**(解像度の使い方を変える)。
7. **U-Net2D / AxialAttn**: (時間×δ) の U-Net skip / 軸別 attention。アーキ族の変更(改善に近いので優先度低)。
8. **GBM-on-bins**: per-bin 手作り特徴 → LightGBM δ回帰 + 平滑(CPU で速い、別ファミリ)。
9. **TTA/合議**: flip/prefix TTA、複数復号(mean/DP/ContOpt)の行別合議(仕上げ用に温存)。
