# v85 — GRの別表現をPFに入力する研究(struct不使用, ユーザー発案 2026-07-24)

## 前提と制約
- 課題: 自己相似性(Milankovitch周期)でPFが位置を追えない(±15ftエイリアス)。GR自体の表現を変えて追いやすく。
- ★既知の鉄則(v76/v78): **絶対GRレベルを消す表現は死**(生点差分7.784≫勾配8.97≫NCC15.5)。
  絶対レベル＋低周波が反エイリアス信号。prefix使用可(井戸レベル変換パラメータ推定に)。
- 検証台: v85/gr_transform_v85.py。GR変換T()をhw/tw両方に同一適用→struct-free PF(pf_tuning)へ→
  r0固定で本番eval overall RMSE と 無変換r0との誤差相関ρ(=別エンジンになるか)を測定。PARAM=r0/p_1..p_5。

## 結果
### v85-1 antieq(希少性拡張=anti-equalization) — ★大崩壊でclose
15井: 無変換4.27 → antieq **12.10**(勝率13%)。ρ=0.29(脱相関)だが単体崩壊で脚価値なし(blend−0.01)。
機構: **振幅軸の非一様warpはPFの固定σガウス尤度と非互換**。稀な領域を引き伸ばすと小GR差が巨大残差化→
大域σが不整合→尤度崩壊。仮説「稀な値を識別的に」は棄却。
### ★切り分け(v85-1から立つ設計則)
GR表現変換のうち**振幅軸を非一様に歪めるもの(antieq/log/rank)は全滅**、
**深さ方向フィルタ(lowpass/band=振幅単位を保つ)だけが許容**。
= 「絶対レベルを保て」を「振幅軸を触るな、触ってよいのは深さ軸だけ」に精緻化。
### v85-2 logamp(対数振幅圧縮) — ★単体効果は標本まぐれ、脚としては有効
- 60井SEED1: 単体+0.78(8.43) → **別標本で否定**: 200井SEED3 単体**−0.96**(10.31)/p_2 −0.93/g0=25 −0.25/g0=60 +0.31。
  **単体効果は標本依存=信頼できず**(★200井まぐれの実例。全773井が必要な理由)。
- ただし**脱相関脚としては一貫**: ρ0.58〜0.91、blend −0.47〜−0.78。役割はaffine/bandcapと同じ「blend脚」。

### v85-3 lowpass(低域GR) — ★単体大崩壊(60井)
