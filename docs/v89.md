# v89 — 入力の定式化を作り直して 5.x に至る(物理錨なし)

> ユーザー指示(2026-07-24): 現状資産で何らかの学習をして RMSE 5.x に。**物理錨(struct)は信用できないので使わない**。
> tabular/TCN は散々試したが「入力するモデル(=入力の定式化)が誤っているかもしれない」。
> PF や gf は**逐次推定なので入力値が近く(相関して)なっている**と考えている。
> tabular/TCN を使うなら何を入力すべきか / 使わないなら入力は何か、をひたすら考えてほしい。
> **CV-LB が追従しているもの**を使うのが好ましい。

## 1. 事実の整理(なぜ今の入力では頭打ちなのか)
- **タスクの正体**([[error-anatomy-ref]]): `TVT = ANCC − Z + b_well`。b_well=坑井定数(datum, SSE の 57.6%)、
  残りは **dip(区分線形の傾き・折れ点)と datum枝(±1サイクル≈15-16ft のどちらか)**。
- **候補oracleは行2.14** だが **選択は6.4で頭打ち**([[v47-selection-ceiling]])。理由=
  **回帰は bimodal を平均して2枝の中点に落ちる**(構造的失敗)。価値は完全に「各位置でどの枝かを分類」すること。
  枝分類の天井: **K=2→4.45 / K=3→3.55 / K=7→2.61**。mode_rep単体は6.83(=常に1枝=mean級)。
- **硬い行(>10ft誤差の13%行=RMSEの72%)の枝判別は、試した全軸で acc≈0.54 頭打ち**:
  GR振幅 / 時間sticky / GR波形相関 / 空間近傍 / **生GR CNN(0.39≈チャンス)** / 既知帯(corr0.03)。
- v88の実測: **tw点照合は自己相似性を全く解けていない**(hit@2ft 39.5%, 70%区間でデコイが勝つ, 周期16.5ft)。

## 2. 診断: 「入力が近い」の正体
PF/gf/beam/NCC は**すべて逐次(または貪欲)推定で、早い段階で1つの枝にコミットする**。
- コミット後の点推定は互いに ρ0.9+ で相関([[v47-selection-ceiling]] soft×soft 0.986)。
- v47 が枝候補にした「delta順ソートした21候補」も、**全候補が同じ(GR貪欲が選ぶ)枝の近傍**にいるため、
  **真の対抗枝(±1サイクル)を候補が張れていない**。= 「K=3枝」が名ばかりで実は1枝周辺に密集。
- ∴ **枝分類が0.54で頭打ちなのは「情報の限界」ではなく「対抗枝を明示的に評価していない」から**の疑いが濃い。
  v47は「どの候補か」を選ばせたが、**肝心の対抗仮説(=1サイクルずらした軌跡)を入力に持っていなかった**。

## 3. 入力の定式化(本命の主張)
### ★主張: 「コミット済み点推定」でなく「**枝ごとの証拠**」を入力にする
1. **枝を明示的に生成する**(候補生成の作り直し=[[hengck23-ceiling-formulation]]と同義)。
   - PF軌跡 `p(md)` を1本得る(v88の tw PF)。dip形状は枝間で共有(TVTを平行移動するだけ)。
   - 坑井ごとにサイクル周期 λ を **typewell GR の自己相関第1ピーク**から推定(struct-free)。
   - 対抗枝 = `p ± λ`(必要なら `±λ/2`)。= **真の bimodal を構成で張る**(v47の名ばかり枝を修正)。
2. **枝ごとの証拠を、脱相関した多ソース尤度で測る**(v88の成果を使う)。
   - 各枝軌跡に沿って **tw尤度 と self尤度(v88)** の GR-misfit を区間集約。
   - self は tw と ρ0.79 の別推定器。**tw単独では谷が同点でも、self が片枝を否定できる**(v88の診断で hit +4.3pp)。
   - 区間集約は「PF軌跡に沿った点照合の和」なので、**一定rate外挿(E4失敗)を踏まない**(軌跡は既に得ている)。
3. **区間(segment)単位**で扱う。datum枝は region-level なので、行回帰でなく**区間の枝ラベル**が正しい単位
   ([[formulation-diag-segment]] 「行レベル信号ゼロ・誤差=区間branch」と整合)。

### ★入力ベクトル(tabular/TCN 共通、struct-free)
区間ごと(または行ごとに区間集約を持たせて):
- `misfit_tw[b]`, `misfit_self[b]` for b∈{0, −λ, +λ}(多ソース×多枝の証拠テンソル)
- `gap = misfit[0] − min(misfit[±λ])`(=枝の確信度。負なら対抗枝が勝っている=危険信号)
- `λ`(周期)、`p−lk`(datum相対)、区間の dip・長さ・既知帯からの距離
- v88の脱相関脚そのもの(tw+self合成PFの点推定)と、tw PF との差
- **committed点推定は"参照"としてのみ入れ、主役は枝証拠**

これが v47/v69/v87 の入力(コミット済みPFバンクの束)と根本的に違う点:
**「答え(点推定)」でなく「対抗仮説それぞれの尤度(landscape)」を入れる**。

## 4. tabular/TCN を「使う」場合 / 「使わない」場合
- **使う場合(本命, CV-LB追従が良い)**: 上の枝証拠ベクトルを **GBM(tabular)** に食わせる。
  tabular は [[cv-lb-policy]] で **CV−0.061→LB−0.07 と比例追従**(v28実績)。self/nbr/smooth PF も無調整でCV=LB追従。
  → **枝証拠 → GBM 回帰**をまず試す。ただし回帰は中点に落ちるので、**枝分類(どの b が真か)を補助タスク**にする。
- **使わない場合**: 枝証拠を emission とする **struct-free の sticky 線形鎖 forward-backward**
  (状態=枝 b∈{下/中/上}、遷移=枝は滅多に乗り換えない、emission=多ソースmisfit)。
  = v47のHMM案を **(a)明示サイクル枝 (b)v88多ソースmisfit** で作り直したもの。
  **bimodalに回帰でなく確率分類で当たる**唯一筋。TCN は生GR入力で0.39=チャンスだった([[v47-selection-ceiling]])ので**生GR系は避ける**。

## 5. CV-LB 追従性(採否の基準)
- 追従した: **self/nbr/smooth PF, tabular**(無調整でCV=LB同時改善, v28/v27)。
- 追従しなかった: **struct(v79 LB死), NN脚(v62 L5 CV5.93→LB6.588の大逆行, v52 TCN非転移)**。
- ∴ v89は **struct禁止 + tabular主役 + (使うなら)NNは補助**。枝証拠は self尤度由来なので追従側の性質を持つ見込み。

## 7. ★U-Net(非逐次)の入力定式化 — ユーザー steer を受けた本命設計
> ユーザー: 物理錨なしU-NetでRMSE10に至れる(v64実績≈9.5)。U-Netは非逐次。GR表現/複数入力でシグナルを得られるかも。
> **RMSE15付近=直線(最終値コピー)**。**直線にならないための対策**が要る。

### なぜ非逐次が効く可能性: 逐次(PF/gf)は早期に1枝へコミット→点推定が相関(D1で実証)。
U-Netは **MD×TVT のマッチ画像を丸ごと見る**ので、真の枝経路は画像上の"尾根"として可視。
点照合の局所性(D1の限界)を、空間文脈で越えられる余地がある。

### ★「直線(RMSE15)にならない」ための核心=出力と損失の定式化
- 直線=**回帰が安全なヘッジ(最終値コピー/枝の中点)に潰れる**。[[v47-selection-ceiling]]「回帰はbimodalを中点に落とす」と同一病理。
- 対策: **出力を δ(相対TVT)の分布(softmax over δ bins)にし、CE損失**で学習。
  スカラー回帰は必ず平均へ潰れる(=直線)が、**δ分類は質量を置かねばならず、CEが誤配置を罰する**ので直線に逃げられない。
  = v50 StageC(枝commit oracle 5.17)/ v64 decoder の路線。
- 補助: 直線解へのペナルティ(予測δの行間分散が小さすぎるとロス)、oracle-δへの補助CE。

### ★入力(マッチ画像, struct-free, 複数チャネル)
行=MD(eval), 列=δ(基準dip線 or last_known_tvt 相対), 値=GR整合コスト。**複数チャネルで脱相関情報を束ねる**:
1. tw-GR整合コスト(生)
2. **self-GR整合コスト(v88 self参照)** = tw と ρ0.79 の脱相関ソース(D1でselfは選択に僅かに効く)
3. GR表現違い(v85 logamp/affine)の整合コスト = 別の脱相関軸
4. ガイドチャネル: tw-PF軌跡 / v88 self合成PF軌跡 を画像に焼く(=良い初期枝のヒント)
- GR表現(ユーザー言及): 生点差分が最良([[v76]])なので**生GRのNCC/差分を主チャネル**、logamp/affineは副チャネル。
- 複数入力(ユーザー言及)= 上の多チャネル。**単一GR表現に頼らず脱相関ソースを空間的に重ねる**。

### 判定基準(CV-LB追従)
- [[v64-pf-free-unet]]: 出力ブレンドは死(転移率1.14=空間prior濃度法則)。**特徴注入(自己申告劣化検出 std/top2gap)が活路**。
- → v89 U-Netも **出力を直接使わず、U-Netの δ分布から top2gap/entropy/argmax-δ を特徴化**して tabular(追従側)へ渡すのが安全。
  = 「U-Netに枝を見させ、その確信度を tabular が消費する」ハイブリッド。

## ★★E-UNet: struct-free 非逐次U-Net(PF中心δ画像) — PFを大きく上回る(2026-07-24)
### 設計(全て struct-free)
- δ枠中心 = **tw-PF軌跡(v88, struct錨なし)**。U-Netは「PFの枝誤差δ」を予測=易しいタスク化。
- 9ch全struct-free: c0窓GR差/σ, c1-2 NCC vs typewell(W16/W64), c3 NCC self, c4 NCC nbr, c5被覆,
  c6 PF信頼stripe(δ0), c7 lk錨stripe, c8 mdsランプ。**c1-4のwindowed NCC が"血管(波形シーケンス照合)"を担う**。
- 出力=**列softmax over δ + CE損失**(v64トレーナ流用)=回帰でなく分布→**直線に潰れない**(ユーザー懸念に対応)。
- 真δ(=真−PF)が±45ft窓内=**100%**(PF中心なので学習可能行を取りこぼさない)。

## 血管表現の視覚探索(ユーザーsteer)
- 生GR値の相似行列=eval帯で崩壊(GRオフセットdrift)。**局所z-score(形)**が必須。
- 形×列正規化でも**点照合では真の血管がデコイ水平バンドに埋もれ視認困難**。
  → **窓(波形シーケンス)照合=windowed NCC が血管を浮かせる**(U-Netのc1-4がこれ。7.38の主因)。
- 次の representation改善: マルチスケールNCC積 / self・nbrの形照合 / GR別表現(logamp)チャネル追加。

### PFフリー(非逐次localizer)の壁 — B路線
- 中心を平坦線(lk水平コピー, PF不使用, 非逐次, RMSE15.9)にして GR画像だけで学習 → fold0 **12.89**。
- **連続性損失(血管修復, δ経路のL1平滑)を CONW=0.05/0.15 で追加 → 12.88/12.88 = 無効**。
- ★診断: PFフリーの頭打ちは「経路の粗さ」でなく**枝選択(間違ったサイクル)**。連続性は間違った枝を滑らかにするだけ。
  **GR画像を非逐次で読むだけでは±サイクルの枝を解けない**(v47の0.54の壁と同根)。
  PFの「既知帯アンカーから逐次伝播して枝を解く」逐次性こそが枝解決の本体だった。
- ★未検証の残案: 画像チャネルはNCC中心=**絶対GRレベルを捨てている**。[[v76]]の「絶対レベル/低周波が反エイリアス信号」に反する。
  affine較正した**絶対GR値マッチ**チャネルを足せば、非逐次でサイクルを区別できる可能性(未検証)。

### 到達点と限界
- struct-free U-Netでの確定改善: **PF 8.72 → long+grad 8.24**(堅い)/ banks 8.05(不安定)。
- **5.xには遠い**。根本限界は枝判別の壁。U-Netは①PF背骨があれば訂正で効く ②GRだけで枝は解けない、が結論。

## ★B(PFフリー非逐次localizer)の決定的診断 — 自己相似の壁を視覚証明(2026-07-24)
PFフリー(平坦線中心, GR画像のみ)を色々試した結論:
| 方法 | fold0/全井 RMSE |
|---|---|
| 平坦線(直線, 学習なし) | 15.9 |
| U-Net per-bin(long+grad) | 12.89 |
| U-Net per-bin(13ch: +affine絶対レベル+self+Z物理) | 13.12(改善せず) |
| 連続性損失(血管修復) | 12.88(無効) |
| DP-trace(大域経路, 生emission) | 15.9(潰れ)〜22.9(デコイ固着) |
- ★**emission診断(render_emission_v89.py)で視覚証明**: GRマッチのemissionは**自己相似の水平平行バンドの海**で、
  **真経路は最明尾根ではない**(デコイと同じ明るさ)。hard井でDPは+28のデコイに固着し真経路(−45)を辿れず。
- ★**結論=情報の限界**: GRマッチのemissionには「どのサイクルが真か」の情報が無い。
  だから per-bin U-Net も DP も大域法も、**非逐次では枝を解けない(12-13が限界)**。表現やモデルの問題でない。
- ★**PFが8.7を出せる理由**: PFは**(位置,レート=dip)状態を追跡**し、レートの慣性で真の降下経路を辿る。
  位置だけの非逐次法にはレート状態が無く潰れる。→ **自己相似の壁を越えるにはレート状態を持つ逐次(FB)フィルタが必要**。
- ∴ **PF/struct/nbr なしで <10 を切る唯一の道 = (位置,レート)グリッドFB(v48格子のstruct-free版)**。逐次性は持つがPF/structではない。

## ★SDF転用実験 (2026-07-25) — 出力ヘッドをsoftmax分類→符号付き距離場(変位回帰)へ
### 仮説
- 「今回の方法」(学習表現capaug emission + bootstrap中心 + 非逐次DecV)の**入力は同一**のまま、出力ヘッドを差替。
- softmax-δ分類 → **SDF/変位場**: 各セル(t,δ)が「真δまでの符号付きオフセット s(t,δ)=dtrue−offs[δ]」を回帰。
- 読み出し: 各セルが true δ を offs[δ]+s(t,δ) と投票。近傍セル(|s|小)を softmax(−|s|/τ)で重み付け平均 → δ_hat。
- 帰納バイアスがsoftmax分類と根本的に違う(距離場は滑らか/全セルが変位を主張=Hough的) → **脱相関脚**になりうる。枝両義でも滑らかに補間する挙動が異なる可能性=面白い。
### 手法
- データ=既存 learned_boot2.pkl(入力・bootstrap中心は softmax boot2 と同一)を流用。archはddil。
- target s_tgt=clamp(dtrue−offs, ±R=20ft)。loss=smooth_l1(s_pred,s_tgt)。読み出しτ≈4ft。AUXCE(softmax補助)は0で開始。
- SAVE_OOF で softmax boot2 OOF との ρ(脱相関)と overall RMSE を測る。
### 検証条件
- 必ず fold0 で softmax boot2(fold0 RMSE 10.88/overall 11.94)と同fold比較。struct/PF/nbr不使用は継続。
- 判定: standalone overall RMSE と、boot2 OOFとの ρ(低いほど脱相関脚として価値)。

- 結論: **脱相関はアーキ(非逐次vs逐次)由来で出力ヘッド由来でない**の再確認。SDFはboot2の"置換"にはなるが"追加脚"にならない。
