## 診断B: 残差の3スケール分解(datum/branch/fine)

TVT予測 = datum(b, 坑井単位) / branch(サイクル枝, 区間単位) / refine(細, 行単位) の合成、という仮説を oracle 除去で検証。

**① |残差|帯別 RMSE²寄与**
| \|r\| 帯 | 行% | RMSE²寄与 |
|---|---|---|
| 0–3ft | 58.0% | 3.2% |
| 3–7.5 | 26.7% | 15.8% |
| 7.5–12 | 8.6% | 18.6% |
| 12–20 | 5.1% | 27.9% |
| 20+ | 1.7% | 34.5% |
→ **branch-scale(\|r\|≥7.5ft)= 15.3%の行が RMSE²の 81.1%**。

**②③ 3スケール分解(oracleで各スケールの真offsetを除去した到達RMSE)**
| 状態 | RMSE | 賞金 |
|---|---|---|
| full(現状) | **6.42** | — |
| −datum(坑井中央値除去=坑井bを当てる) | **4.51** | datum −1.91ft |
| −segment(rolling median窓101除去=区間枝を当てる) | **0.18** | branch 追加 −4.33ft |
→ 誤差内訳 ≈ datum 1.9 + **branch(区間) 4.3** + fine床 0.18。**−datum 4.51 ≈ 既知の自由シフトoracle4.45([[v47-selection-ceiling]]/v33)と一致**=診断が健全。区間単位で複数シフトを許すと oracle が 0.18 まで落ちる(=multi-cutの上限)。

**④ 行レベル推論が不適の決定的証拠**
- 残差 **lag-1 自己相関 = 1.000**(白色ノイズなら0)。行レベルのノイズが実質ゼロ。
- **fine床 0.18ft**。行ごとに当てるべき信号が存在しない。
- 坑井内 最大持続レベルシフト 中央12.35ft、**≥15ftの途中flip坑井 36.2%**。

→ 誤差は100%「ゆっくり変動するオフセット(datum＋区間枝)」。**行レベルMSEは的外れ**(当てる行信号が無い＋双峰を平均に潰す)。

## 結論(次モデルの定式化)

「良いモデル＝より強い行回帰器」ではない。組み直しの方向:
- **入力**: PF候補15本を*集合(set)*として消費(139列の焼き直しでなく)。struct priorは軽い数信号に圧縮。
- **決定単位**: 行でなく**区間(segment)**。1区間に~100倍の証拠が集まる→行レベルの枝判別56%限界を破れる可能性。
- **出力**: 区間の枝の離散決定 ＋ 区間内 refine。**MSEでなく枝をコミットさせる損失**。
- 転移安全: PF候補を土台に残す(PF-free v70/v71はLB非転移で死。v69_4 comboのNN脚 w_nn0.54はΔ+0.15で転移)。

留保: 区間枝−4.3ftは oracle(真の枝を知った上限)。情報限界(~56%)で全ては取れないが、**集約単位を行→区間に上げる**のが本質的レバー……という仮説を診断C/Dで検証した(下記)。

## 診断E: 区間offsetの正体 — 連続ドリフト vs 離散flip(`diag_offset_nature_v69_4.py`)
within(坑井内offset=r−坑井中央値)を drift(直線=dip/rate系統) + steppy(非線形の段) + fine に分解。
| 成分 | within分散% | 正体 |
|---|---|---|
| drift(直線) | 46.5% | 距離で累積する系統誤差(dip/rate外挿ずれ) |
| steppy(非線形段) | 53.3% | 段は小さい(下記) |
| fine | 0.1% | ≈0 |
- **段差サイズ: 105段中94%が3-8ft、≥12ftは1%**。→ **±15ftサイクル枝flip(datum両義)は稀**。診断Bの「36%が≥15ftシフト」はrolling medianのmax−minがドリフトを"シフト"に数えていただけ。
- within R²(直線当て)中央0.254(R²>0.5は28%/R²<0.2は41%)=坑井は不均一(ドリフト型28%/段型41%)。
- **md_since帯別 within RMSE: 3.57→5.76と遠方で伸びる=ドリフト累積の署名**。

### ★診断B〜Eの最終読み(戦略修正)
誤差は**離散サイクル枝flipが本丸ではない**(それは稀)。正体は≈半分が**なだらかなドリフト(dip/rate系統誤差, 距離累積)**＋半分が**小さな段(3-8ft, 短波長面起伏[[v56-ancc-surface]])**。
- ドリフトは**情報限界でなく系統誤差**: 特徴からは予測不能(診断D corr0.05)だが**坑井自身の未来GRからrate再推定すれば直る**=[[v25-smoother-r0計画]]/[[v36-backward-da]]/v30 closed-loop がLBを下げた理由(特徴回帰では見えず逐次再推定で直る)。
- **最有力レバー=ドリフト補正系(smoother/逆方向DA/closed-loop)**。PF内multi-cut(大flip)は稀なので優先度低。小さな段=短波長面はより難。
