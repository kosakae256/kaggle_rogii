# v56 — ANCC 面モデル(実3D地形)と LOWO 面補間エンジン

> 状態: 実装(2026-07-12)。発端はユーザーの着想「XYZ+地層面から実地形を作れないか」。
> 検証済みの事実(docs/v53_explore.md 後日談ではなく本ドキュメントが一次記録):

## 確定事実(2026-07-12, 250井検証)
1. **TVT ≡ (ANCC − Z) + b が厳密成立**(傾き−1.000005, 例外なし)→ タスクの正体 = ANCC面深度の軌跡沿い予測。
2. **b = typewell の ANCCトップ TVT**(ズレ med 0.25ft)。ただし **test typewell は TVT,GR のみ(Geology列なし)**
   → b は既知プレフィックスから回収: `b̂ = median_prefix(TVT_input + Z − ANCĈ)`。
   この形なら誤差 = prefix→評価ゾーン間の**面誤差の変化分**(絶対誤差でなく相対、空間相関でキャンセル)。
3. 井戸間の面整合: **d→0 で med 2.5ft**(登記ズレ小=一枚もの)。300-600ft med13 / 600-1200ft med24(点ペア差=傾斜込み)。
4. 6面(ANCC〜BUDA)は平行 → フィット対象は実質 ANCC 1枚。
5. ANCC等は train 専用列 → 推論で使えるのは「trainから作った面モデル」のみ(nbr特徴と同じ立て付けで合法)。

## LOWO 実験(このバージョンの主実験)
- 各井戸 w を除外し、他772井の (X,Y,ANCC) 点群(10行間引き)から **局所加重平面フィット**で
  w の軌跡沿い ANCĈ を予測(KNN≤128, Gaussian距離重み, ロバスト1回再重み付け)。
- b̂ = prefix(TVT_input行)の median(TVT_input + Z − ANCĈ)。TVT̂ = b̂ + ANCĈ − Z。
- 評価: 全行プールRMSE / fold別 / 井戸別(+最近接train距離との散布, ECDF, Meiryoグラフ)。
- 分解: b̂ を真値(b_true=med(TVT+Z−ANCC_own))に置換した oracle-b 版も測り、面誤差と b誤差を切り分け。
- 参照線: struct(v38式)≈9.7 / 純PF 8.1-8.6 / v52 GBM 6.28。**7台なら新priorとして全系統波及**。

## 使い道(結果次第)
1. struct 2.0: pfA錨 / gf prior / v50 evidence prior ch の置換候補(datum曖昧性なしの絶対Z面)。
2. v55 生成器2.0: フィット面の中に合成軌跡を掘る(近傍整合の根治=ユーザー指摘のXY問題解消)。
3. tabular/TCN の特徴(ANCĈ−Z, 面の局所傾斜, 近傍点距離, フィット残差σ)。

## 結果(2026-07-12)
- **LOWO 全773井: overall 15.51**(oracle-b 15.98 — prefix相対錨は損失ゼロ以上)。fold 14.1/14.2/14.0/17.3/17.6。
- 距離帯別 井戸RMSE med: <300ft **5.16**(n16)/ 300-800ft **7.25**(n469=61%)/ 800-2000ft 10.77(n263)/ >2000ft 17.12(n25, prefix-hold fallback)。
- **struct(9.71)との比較**: 単体では全帯で struct 優位(own-prefix外挿の強さ)。しかし
  **誤差相関 0.489 / v56勝ち 240/773(31%)/ struct>10ft の188井中51本を v56 が<10ftに救出**
  = 第3の独立情報源(GR系/struct系/面系)。単体エンジン不採用、特徴/prior/生成器土台として採用方向。
- 実装教訓: **平行1本井戸の点列で平面fitが幾何縮退**(初版は数百ft誤差)→ 井戸多様性強制(4本×≤48点)+スロープのリッジ(LAMS=5)が必須。
- 深い知見: 隣接井戸(200-400ft)の面差は ±10-30ft の滑らかなドリフト
  = **datum±15ft両義性の物理的正体は面の短波長起伏**(どんな補間でも500ft間隔からは復元不能=GR照合が本質的に必要な理由)。
- 距離は test でも計算可能(train XY への距離のみ)→ surf_dist/σ(距離) は合法な test 特徴・ゲート。

## 判定(2026-07-12): ★提出チェーンへは不採用(ユーザー決定)
- 特徴注入(4列, 本家GPUノート v56/train_tabular_v56.ipynb): **微悪化**(ユーザー実行)。
- 後処理ブレンド(距離ゲート, OOFチューニング): best = step w=0.1(d<300)/0.05(300-800)/0 で
  **6.2471→6.2371(−0.0100)だが fold別で符号が割れる**(勝2負2分1)。
- 解釈: **GBMは面の情報の大半を nbr/struct 系特徴経由で既に保持**。面の独立成分は行レベルでは薄い。
  OOF調整2dofの−0.01は overfit_policy 的にPBで剥がれやすい族 → 不採用。
