# v67 — ARF: 自己回帰ニューラルフィルタ(PF不使用の逐次モデル)

> 発端(2026-07-14 ユーザー): Shrey(8位)が逐次モデリングで上位。「PF でなく・逐次で・自己回帰(LSTM/RNN)で
> 精度出せないか」。物理prior(struct)を使う版/使わない版の両方を作りたい。

## 仮説
純逐次(自己回帰)は「早期 drift して居着く」失敗を持つ(Shrey 実証: worst 86454a6f=43.86)。
それを避けるには **毎ステップ GR で絶対再アンカー** + **双峰を保つ mdn**。この2点を入れた
「学習フィルタ」= 微分可能なミニ PF を、**PF 不使用**で作る。狙いは単体勝ちでなく **PF-GBM と別ファミリー = 良い多様性**
([[v28-oof-reconstruction]] で r014/pf123 が同族・相関0.89で冗長だった裏返し)。

## 設計(`v67/arf_v67.py`)
- 各 eval ステップ t:
  1. **emission**: 走行位置 P の周りの δ グリッド(±48ft)で `typewell-GR(P+δ)` vs `観測GR` の照合尤度ストリップ (D次元)
     + **照合ピーク δ**(GR が最も合う位置)を明示特徴として付与(localization。v14「点GRは弱い」対策=収束が激変)
  2. **GRUCell**(hidden=H)に [emission, peak, 幾何, 観測GR, (struct)] を入力 → 状態更新
  3. **mdn ヘッド(K成分)**で **補正 Δ=(真位置−現在P) を予測**(★自己補正=drift を打ち消す。真増分でなく現Pからの補正)
  4. 点推定 Δ = 混合平均 → P ← P + Δ(自己回帰ロールアウト)
- **双峰**: mdn の混合で datum 両モードを保持 → posterior mean(error_anatomy §4)
- **STRUCT トグル**: `STRUCT=1` で `struct_tvt−P`(soft錨)と `1/struct_sig` を入力に足す。`STRUCT=0` = **純GR照合(物理prior無し)**
- **PF 不使用**(粒子なし)。この学習フィルタが PF の役割を置換
- **TBPTT**(チャンク=160)でメモリ有界。損失 = mdn NLL(補正)+ λ·位置MSE

## 検証(★最重要)
- **既定は leave-field-out**(`CV_MODE=field`: XY を KMeans で N_FIELDS 分割 → フィールド丸ごと holdout)。
  NN脚は井戸 GroupKFold だと**同フィールド井戸が train に残りフィールド指紋を過学習**(v34 墓標: in-sample4.99/井戸OOF6.75/LB7.28)。
  **leave-field-out を通れば転移する** — CV の数字は field-out で見ること([[cv-lb-policy]])。
- 井戸 GroupKFold も `CV_MODE=well` で可(参考・楽観値)。

## 使い方
```bash
# 1) キャッシュ構築(初回のみ, 生CSV→per-well系列。全773坑井, ~数分)
.venv/Scripts/python.exe v67/arf_v67.py cache
# 2) 学習(STRUCT 0/1 の2本 = 物理prior寄与の切り分け)。GPU 推奨
STRUCT=0 CV_MODE=field .venv/Scripts/python.exe v67/arf_v67.py train   # 純GR(物理prior無し)
STRUCT=1 CV_MODE=field .venv/Scripts/python.exe v67/arf_v67.py train   # struct錨あり
```
env: `STRUCT(0) CV_MODE(field|well) N_FIELDS(16) EPOCHS(12) BATCH(16) LR(1e-3) HIDDEN(160) KMIX(3)`
`DR(48) DSTEP(3) GR_SIG(15) CHUNK(160) LAMBDA_POS(0.2) N_WELLS(0=全) EVAL_STRIDE(1)`
出力: `arf_oof_{struct|nostruct}_{cv}.npy`(行別 posterior-mean TVT)+ `results_*.json`。

## スモーク実績(2026-07-14, 40坑井/stride8/8ep, 実装検証)
- 端到端 OK: leave-field-out 分割・TBPTT 学習・mdn・OOF 生成・STRUCT 0/1 両経路。**peak特徴で loss が数百→~20 に収束**。
- **STRUCT=1: overall 9.865 / 中央 7.11**(carry-last 15 を切り PF帯へ。錨が drift を抑制)。
  ※ RMSE ≈ struct 自身の LOO 9.7 に近い = **struct を強く頼っている(コピー気味)可能性**。本学習で struct を超えるか要確認。
- **STRUCT=0: overall 21〜29(不安定)= 純自己回帰の drift を再現**(Shrey の失敗モード)。
  40坑井では GR からの自己アンカーを学びきれず drift。**本データ773坑井で GR 自己アンカーを学べるかが「物理prior無し逐次」の可否の分かれ目**。

## 判定と次
1. **本学習(773坑井・GPU・EPOCHS 12+)を STRUCT 0/1 × leave-field-out で**。見るのは:
   - **STRUCT=0 が drift を脱して carry-last(15)以下・できれば PF帯(~8)に入るか**(= 物理prior無し逐次の成立可否)
   - **STRUCT=1 が struct 自身(LOO~9.7)を超えるか**(= GR wiggle の上乗せがあるか。無ければ struct コピーで無価値)
2. leave-field-out で PF-GBM(v52/v62)と**誤差相関**を測る → 低ければ**多様性の脚**として blend(単体勝ちは期待しない)
3. STRUCT=0 が drift するなら**強化レバー**(優先順): ①emission を窓NCC化(点GR→GR窓の相互相関=localization強化) 
   ②δグリッド拡大/2段(粗→細) ③LR/CHUNK 調整 ④posterior-mean でなく mdn の主モードで rollout(双峰の谷回避)

## 実装メモ
- 補正ターゲット `Δ=真位置−現在P`(真増分でなく)が自己補正の肝。真増分だと P がズレたまま補正されず drift する。
- emission は typewell を一様TVT grid(0.5ft)へリサンプルして torch.gather で高速化(per-well grid をパッド)。
- struct prior は [[v66-struct-upgrade]] の `prior_v66_leanv1cumul_train.pkl`(採用版)を使用。
- 現状 emission は点GR照合。GRU が時間方向に積分するので静的点GR(v14)よりは強いが、窓NCC化が最初の強化候補。
