# v58 — DTW 実験(GR↔typewell アライメントの DP 族を分解検証)

> ユーザー依頼(2026-07-12): DTW を実装して精度検証し、改善の方向を示す。
> 前提知識: beam 解剖([beam_anatomy.md](beam_anatomy.md))= 非単調±2 DP+枝刈り+Z無視で 16.6。

## 設計(段階分解 — どのレバーが効くかを切り分ける)
| 変種 | 単調性 | Z結合 | 復号 | 意図 |
|---|---|---|---|---|
| V0 | 単調(古典DTW, 下方向のみ) | なし | hard | 素のDTWがこの問題で死ぬ点の定量 |
| V1 | 非単調(±K) | なし | hard | beamの「枝刈り」寄与の分離(厳密DP) |
| V2 | 非単調 | **あり**(移動コスト=\|Δj−ΔZ/step\|·λ) | hard | 物理priorの寄与 |
| V3 | 非単調 | あり | **soft(FB事後平均)** | hard commit の代金 |
- 共通: typewell 0.5ft格子、開始=lk錨、GRコスト=((g−t)/σ_w)²(σ_w=prefix残差で井戸別較正)。
- 評価: beam解剖と同一80井、pooled RMSE + 井戸別。参照: beam med 16.6 / PF(pf_1/tw) 8.89 / rmse15。

## 結論と「改善するなら」の答え
1. 効くレバーの序列は測れた: **非単調化(必須) < Z結合(+0.3) < soft事後(+5.8)**。単調性はこの地質(層を上下に出入り)と原理的に矛盾 = 古典DTWは定式化ごと不適合。
2. ただし改善レバーを全部積む(非単調・Z遷移・井戸別σ・soft・帯制約・多スケールコスト)と、
   **行き着く先は既に持っている系そのもの** — δグリッドFB = v48(8.85)、粒子版 = PF(8.1-8.6)。
   DTW固有の「アライメントコスト」観点が足す情報はゼロで、引く制約(単調性)だけがある。
3. **判定: DTW路線は closed**。残る使い道があるとすれば軽量特徴(整合コストのマージン等)だが、
   その席は v52 の beam_ 特徴が既に占有(弱いが低相関)。追加工数に見合わない。
4. 副産物: hard commit の代金 ~6ft(V2→V3)を同族内で再計測 — 「soft が生存則」の追加サンプル。

## v58b — 物理prior入り(ユーザー指摘の追試, 40井)
- 構成: δ格子FB × **NN emission(v50 sim, OOF)** × **struct帯prior(LPR)** × prefix錨。決定論的。
- 結果: best(β2,σδ2,ε1e-3,**LPR0.1**,錨) = **15.01** / LPR0 = 19.41(**prior寄与−4.4ft=ユーザー直感の実証**)/ 錨寄与ほぼ0。
  参照: PF 9.07 / struct 13.58(同一井戸)。
- 敗因: sim単独emissionは尤度にならない(**v50「hybrid PoE必須」の再現**。PFでW=0.02の弱乗数なのは必然)。
- 家族の不動点: GR尤度×sim×prior のグリッドFB = **v48+NN emission ≈ 7.5-8見込み** = r0+NN(7.45)と高相関の7本目バンク。
  v54がper-seed候補で同情報を摂取済みのため、単独追求は費用対効果低。
- 回収先(最小コスト案): v48 gf特徴生成に ×exp(β·sim) を追加(create側1行)。
- **判定: DTW/グリッドFB路線 closed(知見=物理prior有効・sim単独不可を持ち帰り)。**
