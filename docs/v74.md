# v74 — GRフリーで CV<7 は可能か(操舵信号の発掘と情報予算の確定診断)(2026-07-20)

## 背景・目的(ユーザー指定)
Kaggleフォーラムで Angus Chang(64位)が「**single pure physics-based model: CV 6.85 / LB 6.577**」と発言
(観測に何を同化しているかは非公開。Poobearの質問候補: 水平/typewell GR・軌道幾何・他クエリ井戸/空間構造)。
ここから「**GRを使わずに CV7 を下回れる可能性**」を探るのが本バージョンの任務。近傍井戸・ML使用可。
既存手法の改善ではなく新しい方法を考える。

## 新しい着眼: 操舵逆問題(steering inversion)
- タスクの正体は面深度 `g = TVT + Z` の予測([[v56]]: TVT≡(ANCC−Z)+b)。
- **評価ゾーンの軌道 X,Y,Z は test でも全行既知**。坑井は掘削時にリアルタイムGRでジオステアリング
  されている=軌道のうねりは「ドリラーが層を追った制御応答」=**面の短波長起伏の遅延コピー**のはず。
- これは「GRを直接使わずに、ドリラーが読んだGRの蒸留物(軌道)を観測として使う」= 未使用の合法チャネル…
  という仮説を診断で検証した。

## 診断結果(773井, 全行プール, スクリプトは v74/)

- ただし legal(hold錨+κ走査)は 16.4→16.36 でほぼ不動=**低周波が解けない限り操舵は使えない**。

### 診断2b: struct誤差の正体 = 井戸定数オフセット
- struct 9.703 のうち **井戸ごと定数(datum/累積ドリフト)が 7.73ft**、oracle除去後 **5.86**。
- md_since帯RMSE: 4.7→7.9→10.6→12.7(積分ドリフトの蓄積が実質「井戸定数」化)。
- → GRフリー問題は「**1井戸1スカラー(オフセット)を当てる**」に縮約。必要精度: ρ≥0.47で9.0 /
  ρ≥0.71で8.0 / **ρ≥0.89で6.85**。

### 診断3 (`diag3_offset_obs_v74.py`): オフセットはGRフリーで観測できるか → **できない**
- 観測候補=v56近傍面レベル(off_hat = median(struct−v56面)): **corr(off_hat, off_true) = 0.050**。
  超近傍<300ft(15井)でも 0.22、300-800ft(466井)で 0.13。λ=1 適用は 14.8 に爆死。
  距離帯別 λ*(in-sample)でも 9.703→9.670(−0.03)。
- ρ≈0.05 は [[formulation_diag]] 診断D(特徴からの区間offset予測 corr 0.054)と同水準=**4例目の「観測不能」**。

## ★結論
1. **GRフリーで CV<7 の道は、既知・新規の全チャネルの実測で否定的**。
   - 高周波(<2000ft): struct が既に解いている(操舵prior内蔵)。上乗せ余地 −0.02。
   - 低周波=井戸オフセット7.73ft: 軌道(診断0 legal)・近傍面レベル(診断3 ρ0.05)・特徴回帰(診断D)・
     空間結合([[v42]])・定数転写([[v31]])の全てが死亡。oracle 5.86 は見えているが手が届かない。
   - GRフリー天井 ≈ 9.7(struct)。残るレバーは v66 Tier2-1 ペア勾配「ステレオ」場と方位分割
     ([[competitor_advice]])だが、期待値は −0.2〜−0.5 のオーダー(σ解像度系の実績から)で 7 には遠い。
2. **外部シグナルの読み直し**: Angus の "pure physics-based" は「モデルクラスが物理(状態空間/ベイズ同化)」
   の意で、**観測にはGR(typewell/水平)を同化している可能性が高い**(ジオステアリングの業界標準は
   EnKF=GR同化, [[pf_alternatives]])。CV6.85→LB6.577(LBがCVより良い)は我々の無学習純PF系の転移パターン
   (v34 runmean cons: CV7.106→LB6.532)と同型=学習なし単一物理モデздの署名。
   なお 6.577 は我々の前線(LB 5.864)より後方であり、脅威シグナルではない。
3. 副産物(恒久知識): **struct誤差の構造 = 井戸定数7.73 ⊕ 残差5.86**。GR系チェーンの仕事は実質
   「このオフセット(=datum/枝)の解決」であり、GRの代替は(このデータの範囲では)存在しない。
   操舵情報は v38 GATE が既に消費している — 「軌道を特徴に足す」系の将来アイデアは原則リターンなし。

## Phase E — フィールドGP定式(方法の見直し第1弾, 2026-07-21)→ ★負の結果で撤退
「dip推定→積分」をやめ、prefix正解点+近傍ANCC点を1つのGP事後に統合する定式(`phaseE_gp_v74.py`)。
普遍クリギング(線形トレンド除去)・datum b周辺化・**近傍井戸ごとのレベル自由度τ**(面差±10-30ftの周辺化)
まで実装したが、スモーク(40-60井)で **26-29 vs dip積分エンジン~15 の2倍負け**。
ハイパラグリッド(LA/LC/SF 12設定)は**全設定フラット** = 律速はハイパラでなく定式。
- 敗因: レベル観測ベースのGPは近傍の面差ノイズを評価帯全体に持ち込む。τで周辺化すると今度は
  近傍がレベルについてほぼ無情報化し、勾配情報の伝達はカーネル経由では明示的dip-donor WLSより弱い。
  対等にするには「微分観測つきGP」が必要で、それは実質dip積分エンジンの再発明になる。
- 結論: **GRフリーの定式としては「dip場+積分+系列NN残差」が実測上最良**(レベル補間系はv56/GPの2敗)。
