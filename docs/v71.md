# v71 — PF-free / filter-free iTransformer on δ-band emission image

> 発端(2026-07-15 ユーザー): 「v70 の iTransformer を v50 StageB の形(δ帯 emission画像)で **PFなし**で実装してみたら
> どうなるか。まっすぐになってた線が、GR特性をうまく理解してくれるんじゃないか。まっすぐにする場合ペナルティを与えてもいい」。
> 確定方針(AskUserQuestion): GR証拠=**生マルチ表現マッチ**(v70/v68 cache流用)/ コミット機構=**純iTransformer＋直進ペナルティだけ**
> (PFもFBグリッドフィルタも入れない=「モデル自身がGR理解してcommitできるか」の純粋検証)。

## 仮説
v70 の素の iTransformer は「錨から直進(field 9.67≈錨 9.70)」に崩れた=**scalar特徴を回帰させたから**。
v50 StageB の形(**δ帯の emission "画像" を丸ごと見せる**)＋**GRに乗らないと損する損失**にすれば、
モデルが GR の当たり位置(＝両義の2枝)を見て commit するはず。PF・FBの逐次コミットを借りずに、
**iTransformer(変数attention)＋時間TCN＋直進ペナルティ**だけで commit できるかを測る。

## 設計(`v71/itransformer_img_v71.py`)
- **入力 = struct中心 δ帯(±45ft, 91bin, DSTEP=1)の emission画像 E[B,C=6,T,91]**(PF/FB不使用):
  - ch: tw / self / nbr の GR一致尤度 `exp(-0.5·((ma7GR − refGR@δ)/GR_SIG)²)` × 被覆 + struct prior(δ, 中心0) + self/nbr被覆マップ。
  - v70/v68 cache の tw/self/nbr グリッドを δ帯へラスタライズ(`gr_at` 流用)。
- **核 = iTransformer変数attention(ch間: どの表現を信じるか)→ 時間TCN(dip連続)** = v70 の axial 思想を δ画像に適用。
- **出力 = δ softmax → 期待δ → TVT = center + δ**。decoder は **zero-init**、logits に **LOGB·log(emission集約)** を加算
  → 学習開始が「GR emission追従」(=錨δ0に居座らない)。**これが構造的な"直進しない"デフォルト**。
- **損失 = CE(真δ soft) + W_MSE·(δ/DR)²(posterior-mean) + W_EMIT·emission追従(p を高emission δへ) + STRAIGHT_PEN(明示直進罰,既定0)**。
  - emission追従項 `−Σ p·log(Eagg)` が**ユーザー要望の"直進ペナルティ"本体**: 錨の低emission位置に居ると罰、GR peak に乗ると得。
  - STRAIGHT_PEN(任意): 錨近傍(±margin)に mass があり emission が非中心の時だけ追加で罰(易しい直線坑井は傷つけない設計)。
- **転移ガードレール = leave-field-out**(NN脚のLB非転移を早期検出。[[cv-lb-policy]] / v34/v62/v69)。

## 使い方
```bash
CV_MODE=field STRUCT=1 .venv/Scripts/python.exe v71/itransformer_img_v71.py   # 本命判定(struct band中心)
CV_MODE=field STRUCT=0 .venv/Scripts/python.exe v71/itransformer_img_v71.py   # struct無し(転移安全側/難)
```
env: `CV_MODE(field) STRUCT(1) EPOCHS(15) BATCH(8) LR(1.5e-3) DMODEL(64) ATTN_HEADS(4) NVAR_LAYERS(2)`
`TCN_LEVELS(4) DROP(0.1) LOGB(1.0) W_EMIT(0.3) W_MSE(1.0) TGT_SIG(1.5) STRAIGHT_PEN(0.0) N_WELLS(0=全)`

end-to-end OK: δ画像(C=6,91bin)生成・変数attn+TCN・δ分布→期待δ・field/well CV・OOF・overall。loss有限(~5.7)・NaN無し・GPU 3s。

## 予測(実装前の見立て)
- 直進崩壊は直る(δ画像+emission追従で GR peak を追わざるを得ない)。着地はおそらく **v50B 圏(正直5-fold 7.8〜8.5)**。
  デコーダ核の差(CNN+GRU→iTransformer)は中程度レバー、真の壁は**枝判別**([[v47-selection-ceiling]] 56%)で直進ペナルティは錨崩壊からしか救わない。
- 価値: (1) **PFと誤差が異質な PF-free 脚**=blend価値([[v28-self-nbr-gbm]]型)、(2) 長距離attentionが「終始枝A」的大域整合で ghost判別に上積みの芽。
- **CVはLBを過大評価**(NN脚+struct band中心)。採否は必ず field-out で。
