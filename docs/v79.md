# v79 — v75パイプラインの物理錨をK16に全面差替(create/train/submit)

## 目的(ユーザー指示 2026-07-22)
v75はCVに過適合した物理錨(v38/v66 struct)を使いLBで死んだ(CV6.101→LB6.95)。
**同じパイプラインで物理錨だけK16(kappa_2, space-blockゲート合格済)に差し替えて**特徴を作り直し再学習する。

## ★★LB結果と死因(2026-07-23) — K16gateは動力学注入で死
- **LB 7.129**(CV 6.2420 から +0.887 大逆行)。struct版v75(LB6.95)と同型の転移死。
- **決定的検証**: K16gateを「ドナー≥1500ft制限の劣化錨」(=隠しtest相当)で回すと 200井 **7.95**
  (良錨版6.51から+1.44崩壊)。→ **死因確定: K16gateはrateへの連続的な引き=誤差構造法則の毒**。
  trainではLOO品質の良錨だから効いたが、隠しtestの劣化錨(遠ドナー)では井戸定常バイアスを
  積分注入して崩壊(v76 trend/ir +6〜+20と同じ機構)。
- **v77の転移耐性(space-block −0.94)は「出力blend=有界合成」の話。「動力学への注入=積分」は別物**。
  → 錨は特徴/blendとしてのみ使え。gate(rate引き)としては使うな。structもK16も動力学注入は死。
- 教訓の一般化: **CV=LB測定器が成立するのは無調整の有界合成のみ**。gate/rate系の連続注入は
  錨品質に対して非線形に脆く、CVが良くてもLBで死ぬ。K16gate路線は全面close。
