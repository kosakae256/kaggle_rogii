# v69 — tabular×TCN(v47構成)を 4バンク smooth PF(lag192)特徴で

> ユーザー指示(2026-07-15): 「af, dec10, sharp の3本(当初 smooth 込み4本→smooth除外)で tabular+TCN 推論。特徴量は v47 と同じ、
> **PF出力部分だけこの4本に変える**。エンジンは smooth PF、smooth値=192。PFパラメータは各々ハードコード、後から追加可。
> create/train/submit の3ファイル。実行はユーザー」。

## 仮説
[[v65-pf-tuning]] の相関調査([[cv-lb-policy]] 7)で、**多様化PFブレンドは LB でも両成分より下**([[v28-oof-reconstruction]]系の 50:50=7.498 実測)。
→ その多様バンク(af/dec10=錨ON, sharp/smooth=錨OFF, 相互相関0.54-0.84の2クラスタ)を **v47 の tabular×TCN 選択器**に食わせれば、
単純ブレンドより上(v47実績: 弱PF土台でも GBM→TCN で LB 6.4台)を狙える。

## 変更点(v47 → v69)
- **PF出力=3バンク**(af/dec10/sharp)×(tw/self/nbr)=9候補。v47の7バンク(pf1/2/3・r0/r1/r4・pfA)を置換。
  ※当初 smooth(smooth_tracker, MD-1)も入れたが **ユーザー指示で除外(2026-07-15)** → 残る3本は全て MD-10。
- **エンジン=smooth PF(固定ラグ 192)**。v47実験版は lag16 だったのを本番 192 に。
- **★per-bank 間引き=dec10の仕組みを保持**(2026-07-15 ユーザー指摘で修正)。af/dec10/sharp は **MD-10でチューニングされた**構成なので、
  smooth PF の前に **MD-10 集約(GR mean=denoise)→ smooth PF → 全解像度に補間**する(`DEC_BANK={af:10,dec10:10,sharp:10}`, `run_smoother_bank`)。
  **これで各バンクが本来の解像度で回る**(params だけ持ってきて full 解像度で回すのは誤り)。
  副次効果: **全バンク ~8-10倍速**(smooth除外で full解像度バンクが消滅。実測 lag192/8seed/16well: dec各 1.2s / 旧smooth 9.4s)。
- **錨(struct)= v66_leanv1cumul**(4本は v66 でチューニング)。**anchor_mult は per-bank**(af=6.84, dec10=12.16)。sharp/smooth は錨OFF。
- 特徴量(v9 build_well: beam/formation/NCC/pf_z/dense + self/nbr/z_grad + 集約)は **v47 verbatim**。バンク数非依存で `pf_*_1..4` に自動追従。
- **PFパラメータは各バンクをハードコード**(v65 の best json から取り込み、`create` の `PF_LIB` に literal)。**追加= `PF_LIB` + `PF_BANK`(+錨なら `PHYSICS_BANKS`)に足すだけ**。
