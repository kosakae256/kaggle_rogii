# v64 — PF-free 2D UNet + 合成事前学習(Tucker 3位再現路線、物理prior入り)

> 方針(2026-07-16 ユーザー「v64でそれやろうぜ、物理prior入れてもいいよ」):
> future_experiments ★項目1(2D UNet再現)の実行版。**PF出力を一切使わない** GR照合像から
> (時間×δ)の2D UNet で経路を推定。v63 の教訓「合成はエンジン特徴消費者に効かない」を受け、
> **合成(pseudo)が本来効くはずの画像消費者**で事前学習を試す(v61 P1 はゲート飛ばしで失敗 → 今回はゲート厳守)。

## pseudo 生成器 v2(2026-07-16 ユーザー指摘「今の作り方は不自然」への対応)
v63 生成器の不自然さ = ①滑らかな低周波warp(実地質は**層単位=ブロック状**に変わる)②軌跡が常にdonorコピー。対応:
- **layered warp**: 層境界を Poisson(平均層厚 LTH=25ft)で切り、層ごとに log厚み(THICK_L)・ゲイン(AMP_L)・オフセット(OFF_L)を抽選 → ブロック状の自然な歪み。全レシピ共通。
- **レシピ**(env `RECIPE="synthcol:0.45,trajmix:0.25,surface:0.15,reskin:0.15"` で混合比を自由に):
  - `synthcol`: **完全合成** — typewell 1〜2本の接ぎ合わせ+layered warp の合成柱状図 + **合成軌跡**(landing+うねり+断層)。donor無し=無制限量産。
  - `trajmix`: 地質=実typewell + 合成軌跡。
  - `surface` / `reskin`: v63系(3D面/donor継承)を layered warp 化。
- **typewell劣化**(TW_STRETCH/TW_DROP/TW_NOISE): 消費者に渡す参照は地質列の劣化版=「参照は地質と少し違う」現実を再現。
- **断層**(FAULT_RATE=0.25本/井戸, ±3〜FAULT_FT ft)・**GR欠測合成**(GAP_RATE)・ノイズ3水準混合(v63と同じ)。
- **疑似struct sidecar**: st = 真値+datumオフセット(±ST_DATUM)+相関誤差場(σST_ERR, 相関長ST_CLEN)を生成器が出力
  (`pseudo_st.npz`)。builder はこれを優先使用(donor不要・再センタ不要・c6のσも較正済)。
- 全ノブは manifest.json に記録 → **タグ別 ablation**(q1, q2, ... と作り分けて比較)。
- スケール指針: 画像 ≈1MB/井戸(fp16)なので **NSYN=2000 ≈ 2GB pkl**(トレーナは全載せ。RAM20GB制約内で〜4000が上限目安)。生成は速い(8本6s → 2000本 ≈ 5-10分+画像化 ≈ 20-30分)。

**チャネル(全て PF 不使用)**: c0 窓平均GR差/σ、c1/c2 NCC vs typewell(W16/W64)、c3 NCC vs self疑似tw、
c4 NCC vs nbr疑似tw(donor除外の実train近傍)、c5 被覆率、**c6 struct信頼ストライプ**(v38 struct prior の行σ)、
**c7 lk錨ストライプ**、**c8 mdsランプ**。δ枠中心 st = v51 SIMD の struct 軌跡(=中心も物理prior)。±45ft/0.5ft=181bin, stride16。

**pseudo の再センタリング(重要)**: surface型 pseudo は donor st から数十ft ずれ得る(初回スモークで
ps0001 の窓内率39%)→ **井戸定数シフト+±10ftジッタ**で再センタリング(窓内率1.00、structの粗さは維持)。

## ゲートプロトコル(v61 P1 失敗の再発防止、飛ばさない)
- **T0**: PHASE=pre が pseudo val で成立(RMSE が再センタ後の中心固定(≈|dtrue|RMS~10ft)を大幅に下回る)
- **T1**: fold0 で scratch vs PRE(事前学習あり)を比較。PRE が fold0 RMSE で明確に勝つこと
- **T2**: 5-fold 全部 + fold一貫性 + v63/v52 チェーンとの相関・ブレンド寄与

# 6) T1判定: (5) vs (2)。通れば seeds/folds 展開(T2)+レシピ ablation(q2=RECIPE比変更等)

## 提出(submit_unet_v64.ipynb)
- dataset **rogii-v64-artifacts** = `v64_unet*_f*.pt`(採用ckpt群)+ `struct_field_v38.npz`(コピー済)

- eval行 = 最終既知行の次以降(struct と同整列)。欠け井戸は lk フォールバック。

### v64b: struct-free 版(lk中心・±60ft・8ch)の検証(2026-07-17 日中)
- 動機: 単体LB 9.461=転移率1.14 の主因は struct 依存(prior濃度法則)→ lk は train/test 品質差ゼロの唯一の錨。
  drift 統計: 実 |truth−lk| 井戸p95中央値 18.7ft、lk±60窓で 98.7% の井戸をカバー=窓は成立。
- **scratch f0 = 13.0561 — 脚としては失敗**(v64 6.58-6.80 / naive lk-hold 15)。診断: 崩壊ではなく、
  lk-holdには 16/24 井戸で勝つが**両義井戸で誤リッジに過剰コミット**(|dtrue|8ft の井戸に |dh|19ft 等)。
  「±60ft からGRだけで大域推定」は PF の dynamics/複数仮説が解いている部分で、素の UNet には荷が重い。
  **v64(8.30)の実力の相当部分は struct 由来**の裏付け。
- 継続: ①q7(drift較正済みコーパス: p95 11.6→15.7ft)で v64b の事前学習T1だけは検証(座標捏造ゼロの検証台)
  ②**shift augmentation**(学習時±15ftランダムδシフト)を本命として実装 — st中心の追跡力を保ちつつ
  「δ=0を信じる prior」を壊す=転移1.14のsoft成分と事前学習の座標捏造問題を同時に対処する統合案。
- v64b f1 = 13.3281(f0 13.06と整合)→ **v64b は脚として closed**(f2-f4 は回さない)。
- **★v64s(st中心 + SHIFT_AUG=30)f0 = 6.5572 = CV完全保持**(scratch帯 6.58-6.80 の最良側)。
  中心不信の学習は精度コストゼロ → shift-aug 下での事前学習T1(q3画像)を検証中。
- **shift-aug 事前学習 T1 = 6.6593(+0.10 = seed帯内の中立)** — T0 5.9097。座標不変化しても正転移には至らず。
  **合成事前学習の最終結論: コーパス改善(q1-q7)・プロトコル(pretrain/DA/co-pretrain/低LR)・座標不変(shift-aug)の
  全経路で「中立が天井」**。負転移の芯は複数あり(座標捏造・偽リッジ・盆地固着)、各修正はそれぞれの害を消すが
  正の利得は生まれない=「実GRの照合統計は実データからしか学べない」が本質と結論。事前学習路線 closed。
- **shift-aug 自体は独立資産**: CV保持のまま「δ=0 prior」を除去 → 隠しtestの struct 劣化への頑健化(転移1.14の
