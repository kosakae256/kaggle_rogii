# v30 — closed-loop: GBM×NN ブレンド(OOF)を prior に r0 smoother を再走行(pseudo-satellite)

> **状態: 実装済(未実行)。** ファイル: `v30/closed_loop_v30.py`。実行はユーザー。
> 出典アイデア: [beyond_tabular_proposals.md](beyond_tabular_proposals.md) ②(GSDC iterate-then-re-estimate,
> [analog_competitions.md](analog_competitions.md) #7)。v25 に同思想の試作 `tune_pseudosat_r0_v25.py`(FFBS自己prior版)が
> **未実行のまま**存在するが、v30 は prior を「自分の平滑」でなく**外部の最良点推定(GBM×NN blend)**にする点が本質的に違う。

## 仮説
- 現ベスト点推定(v28 GBM × v29 NN blend, OOF apply_pp ≈6.87)は行単位で強いが、物理整合(GR照合・dip連続)は持たない。
- smooth PF の forward 重みに prior アンカー項 `exp(−0.5((tvt粒子−tvt_prior)/σ)²)` を掛けると、
  **prior が大域配置(datum/高さ)を縛り、PF は GR整合+dip連続の局所補正に専念**する分業になる。
  = 最終出力を「prior 誘導 smoother の軌跡」にする逐次推論(非タブラー)。

## 方法
- エンジン: `v25/tune_smoother_r0_v25.py` の固定ラグ系統スムーザー(**r0_seed32 固定, lag=192, n_seed=32** = LB6.786 実証構成)を
  自己完結コピーし、forward 重み更新に prior 項を追加(**log_lik=GRのみ**に維持=seed加重へ prior を混ぜない, v25 pseudosat 設計踏襲)。
- prior: `tvt_prior = lk + apply_pp((1−w)·gbm_oof + w·nn_oof_RUN)`。**全て OOF**(リーク無し)。
  RUN は `artifacts_v29b/nn_oof_{full|combo}.npz` の先にある方、w は results.json の blend_w。
- スイープ: `PRIOR_SIGS = [None(素smoother), 12, 8, 6, 4]`(調整はσ1個だけ・粗く=overfit-policy)。
  各σで `β·smoother + (1−β)·prior` の粗いβ(0〜1, 0.1刻み)も走査。
- 評価: overall(全行プール) + wells>10。**基準 = prior 自身の overall(≈blend_pp 6.87)**。
- 出力: `artifacts_v30/closed_loop_r0.json`(σごと, 再開可)+ `preds_sig*.npz`(全行予測=後段分析/提出素材)。

## 撤退条件(事前に固定)
- **全σで best β = 0(=prior単独が最良)なら閉ループは prior に勝てず終了**(エコーチェンバー判定)。
- β>0 で prior を有意に下回るσがあれば、submit 統合(test では prior=GBM×NN の test予測)に進む。

- β カーブから ρ を逆算する解析(最適blend RMSE の閉形式)が実測と一致(σ96 予測6.80/β0.33 → 実測6.7997/β0.3)。
