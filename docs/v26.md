## 仮説 / 狙い
- **GBMに入れるPF特徴を"強いPF"に格上げ**する。7.191ノートは GBMのPFが**未調整CPUデフォルト**([[overfit-policy]] 参照: resamp=0.5等の丸値)。
  v25で LB6.786 を出した **smooth PF(固定ラグ, r0_seed32)** を GBM の PF特徴にすれば、入力信号が底上げされるはず。
- v20(調整済PF×7→GBM)は LB7.012 まで到達＝**GBMルート自体は死んでない**。PFを smooth PF に替えて超えられるか。

## 変更点(v20/v24 から)
- **特徴 = v9(pf_tuning_create_train_csv_multi_pf_v9.ipynb)の build_well をそのまま持ち込み**(cell3/5/7 をインライン, **exec無し**)。
  ＝v9特徴(pf_ancc/pf_z/**beam**/formation(FormationPlaneKNN)/dense/NCC/GR統計…)を全部生成。**gsf/heur は入れない**(方針)。

- **PF複数**: `PF_BANK = ["pf_1","pf_2","pf_3"]`(v9系, use_phys=false)。`n_seed=32`。冒頭ハードコード。

- **注入の詳細**: `run_smoother_ext` が smoothed(seed尤度加重)を出し、`_patched_run_pf_ancc` が返す。std=seed間加重std。±CLAMP_FTで爆発をforwardに戻す。

## モデル / 後処理
- **モデル**: LightGBM×3 + CatBoost×3 + XGBoost×3(v20系params, GPU)。**GroupKFold(5) by well** OOF。origin toggle(base/pf/beam)。
- **後処理 apply_pp**: GBM残差 と 基準PF残差(`pf_ancc`−last) を `w_pf=0.09` で blend → ランプ(τ=85) → per-well SG平滑(submit)。

## 過学習の注意(★重要, [[overfit-policy]])
- **GBM+PF特徴は過学習しやすい**(v24 n_seed128で8.026自爆, v10 CV-LB乖離)。★v26は **v9のフル特徴(~200+)** ＝特徴多い＝過学習リスクは高い側。
- 防御: **v24で自爆した gsf/heur の盛り合わせは入れない**(v9特徴+beamのみ=v9/v20で実績ある集合, v9 6.946 / v20 7.012)、**n_seed=32一致**、**GroupKFold by well**、pp_params据置。
- OOF↔LB を **±0.2 ノイズ床込み**で見る。OOFが下がってもLBで確認するまで信じない。**v9特徴でLBが v20(7.012)/現ベスト(6.786)を割れなければ、GBM路線は打ち切って合成に回す**。

## 次の方向(v26内で予定)
1. **ヒューリスティックと合成**: v26 GBM出力 と **smoother+beam+hold(LB6.786, [v25.md](v25.md))** を blend。
   ※素朴平均は双峰を潰す禁じ手だが、GBMとヒューリスティックは別系統なので**粗い重み(直感)で合成**を試す([[overfit-policy]] blend方針)。
2. **現行最強との合成**: 現ベスト = smoother+beam+hold(6.786)。v26が単体でこれに届かなくても、**別系統(学習)として合成で上回る**可能性。
   合成は素朴平均でなく、重み固定 or 不確実性(v9特徴の std/disagree系)ゲートで。
3. gate: すべて **GroupKFold OOF ＋ LB(±0.2床)** で確認。GBM追加DOFの過学習に注意([[overfit-policy]])。

## 結果
- **heur×GBM アンサンブル OOF検証**（`check_ensemble_heur_tabular_v26.ipynb`, 全train eval 378万行プール, submit準拠apply_pp）:
  - heuristic(r0 smoother+beam+hold, =LB6.786と同一エンジン) 単体 **OOF 8.085**
  - tabular(pf1/2/3 smooth PF GBM, OOF) 単体 **OOF 7.796**（＝OOFでは GBM > heur）
  - **ブレンド `w*heur+(1-w)*gbm` ベスト w_heur=0.40 → OOF 7.528**（GBM比 **+0.268**, heur比 +0.557改善）。最適はフラット(0.35〜0.45)・単峰・スパイク無し＝頑健。
  - ★**train↔LB ギャップ大**: heuristic は同一エンジンで **train OOF 8.085 ↔ LB 6.786(+1.30)**。硬い核坑井がtrainに偏るため。→ OOF値はLBと直接比較不可。同ギャップがblendにも乗れば LB 6.786割れの可能性、ただし **GBM側のtrain↔LBギャップは未検証**。
- (LB提出後に追記) blend / GBM単体の LB。

## 所感
- 別系統(学習GBM × ヒューリスティック)の**粗いブレンドが OOF で確実に効く(+0.27, seed床超え, フラット最適)**＝狙い通り。次は blend(w_heur≈0.4)をLB提出し train↔LBギャップの転移を確認。GBMは自由度高く楽観寄りのリスク→頑健なheuristic寄り(0.45)へ微ヘッジ可。
