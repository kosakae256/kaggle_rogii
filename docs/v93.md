## 方針(2026-07-27 ユーザー)

### 信頼できる物理錨 = GRフリー v2 (v91 OOF, LB 10.877)
- 実体: `v74/submit_grfree_selfcontained_v74.ipynb` の clean 5-fold GRフリーエンジン(phaseGエンジン+GRU残差)。
- **val完全除外(場・κ・近傍プールをtrain foldのみで構築)+完全ランダム5fold** の厳格cleanで **CV 10.03**。
- **実LB 10.877**(転移率1.08, submit済み実測)。CV→LBが素直に転移する=**リークのない信頼できる物理予測**。
- アンカーデータ: **`v74/artifacts_v74/grfree_v2_anchor.pkl`** = `{wid: {tvt(3seed平均), sig(3seed標準偏差)}}`(全eval行)。773井、長さはv38 struct(=PF eval)と全一致。
- 生成器: `v74/gen_grfree_anchor.py`(GRF_SPLIT=train/test でOOF/アンサンブル切替、testアンカーも生成可)。

### v62 の方法(土台)
- **同じ近傍構造特徴を7つの別表現で学習し固定重みでスタック**。docs/v62.md、[[v62-multirep-stack]]。
  - L1 GBM / L2 TCN / L3 画像(δ×時間格子) / L4 再訪整合 / **L5 曲線トークン(cross-attention, 柱)** / L6 スペクトル / L7 ranking
  - 採用構成 {TCN 0.4, L5 0.775, L3画像 0.05}、3seed×4member平均で **CV 5.8523**(歴代CV最良)。
- **v62 は v52 の parquet(6バンクPF特徴)をそのまま流用**(`build_field_v62.py` が v52 parquet を消費)。

### v62/v52 の PF = 6バンク (差し替え対象)

## STEP 1 結果(2026-07-27): struct20の位置錨×GRフリーは悪化
- 20井, n_seed32, 非smooth。**struct20 錨なし=6.765 / struct20+GRフリー錨=9.494 (+2.728 悪化)**。
- 原因: ①**anchor_mult=20 は正確な v66 struct場用の較正**で、10ft精度のGRフリーには強すぎ→10ft誤差へ引きずる。②**ancs に GRフリー3seed標準偏差(~0.85)を使い真の不確実性(~10ft)を過小評価**→自信満々で誤目標へ強引き。

- **結論の候補**: (A)anchor_mult下げ(3-8)+ancs現実化(~10ft) / (B)v92 structgate機構(rate弱引き戻し)でGRフリーを効かせる[実証済み]。

## ★★真の原因判明=sigバグ(2026-07-27): GRフリー錨のsigを3seed stdで作ったのが誤り
STEP1で「位置錨×GRフリー=+3悪化」の原因は anchor_mult でなく **sig生成**だった。ユーザー指摘「struct20は物理錨前提で作ってて、錨の性質が全然違うのはおかしい」が正しかった。
- **バグ**: GRフリー錨sig = 3seed std(中央値**0.5ft**)。これは seed間の揺らぎで、GRフリーの**真の不確実性(実誤差~10ft)ではない**。v66 struct sig は較正済(中央値**8.65ft**)。0.5ft は 17倍過小 → mult20 で asig=0.5×20=10ft(v66は8.65×20=173ftで穏やか)= 17倍強すぎ → 15ft外れた目標へ強引き。
- **修正**: sig を定数 **9.0ft**(v66スケール相当)に置換。tvt(位置=3seed平均)は不変。
- **全773井 検証(n_seed32, overall RMSE)**:

  | 構成 | RMSE | Δ(錨なし比) |
  |---|---|---|
  | ① struct20 錨なし | 9.0216 | — |
  | ② **struct20 + GRフリー錨(sig=9ft)** | **7.8533** | **−1.168** |
  | ②' GRフリー錨(元sig=0.5ft) | 9.9169 | +0.895(=STEP1再現) |
  | ③ struct20 + v66 struct錨(元struct20) | 7.4683 | −1.553 |

- **結論**: sig修正で GRフリー錨は struct20 を −1.17 改善(元は+0.9悪化)。**7.85 は元struct20の単体記録(CV7.98/LB7.881)とほぼ同水準**。位置錨機構(_pf_core)は v65 と完全同一で正しく、**sig生成だけが唯一のバグ**だった。
- v66 struct(7.47)は全井overallでは +0.385 良いが **struct使用禁止(転移悪, [[no-struct-directive]])**。GRフリーは転移率1.08の健全な錨。+0.385は mult20 が v66 sig用の較正なので、GRフリー用に再チューニングで縮む見込み。
- **恒久化**: `grfree_anchor_train.pkl` の sig を定数9.0で再生成済(元3seed std版は `grfree_anchor_train_seedstd_bak.pkl` に退避)。tvt不変。
