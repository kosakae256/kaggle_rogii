# v61 — 画像脚(GR照合像 × UNet)+合成事前学習: v52 アンサンブルの第3の視点

> ユーザー方針(2026-07-12): v52(tabular+TCN)をベースに、画像的観点(CNN/UNet)の脚を足して
> アンサンブルで上を狙う。まず P0(画像ベースライン)/P1(合成事前学習)。v53以降の数字は当てにしない。

## 仮説
- tabular/TCN は (MD×δ) の照合構造(ゴースト=平行尾根、断層=尾根の段差)を潰した後の世界を見ている。
  画像脚は「潰される前の生の証拠」を読む唯一の視点 = 誤差の非相関を構造的に出しやすい。
- 事前学習が成否の分水嶺(v36 DA の増幅転移=LB実証 / 3位「合成事前学習が効いた」)。
- 分水嶺2: 入力を **GR側に寄せる**(PF事後を敷き詰めると GBM の別表現になり冗長 — v53の轍)。

## P0: 画像ビルダー(v61/build_images_v61.py)
- 座標系: v50系と同一(評価行を stride16 で bin、δ = struct(st, SIMD由来) ±45ft / 0.5ft = 181)。
- チャネル(6ch, fp16):
  c0 = 正規化diff(窓16平均) / c1 = NCC窓16 / c2 = NCC窓64  … 対 typewell
  c3 = NCC窓16 対 self疑似typewell(自prefixの(TVT_input,GR)を0.5ft格子化, 穴はtwで埋め)
  c4 = NCC窓16 対 nbr疑似typewell(近傍8井の既知プール, v54と同じ構築)
  c5 = self/nbr の有効率(データ有マスクの窓平均, 2値を0.5刻みで合成)
- メタ(EVDと同形): dtrue/wgt/st/bid/y_ev → **v60 トレーナ(EVPKL差し替え)がそのまま食える**。
- 出力: v61/artifacts_v61/imagesR_v61.pkl(実データ)。

## P0 学習: UNet2D(v60実装) × 画像6ch、5-fold
- ゲート: 単体 overall <8 かつ **v52 GBM OOF との誤差相関 <0.9**。fold別の並びも見る。

## P1: 合成事前学習
- 生成: v55 v1 再スキン(TAG=v61pre, 数千本, ノブ混合で難易度分散)。画像脚は照合像しか見ないので
  近傍整合問題は発生しない(生成が安い)。st/dtrue はドナー流用。
- 事前学習(合成のみ)→ 実773 fine-tune(5-fold)。ゲート: 事前学習の有無で CV −0.3 以上。

## P2(P0/P1通過後): v52統合
- v29b式残差ブレンド + posterior統計のGBM特徴注入をCVで比較。判定は pooled + median井戸 + fold分散。

## 結果
### P0(2026-07-12)
- 画像ビルド: 全773井 6ch(~10分, imagesR_v61.pkl)。UNet fold0 学習4.5分。
- **fold0 単体 7.106(ゲート<8 ✓)/ corr(chain)=0.584(ゲート<0.9 ✓✓ — 歴代最低相関の脚)/ corr(v50B)=0.712**
- 素の残差ブレンド: chain fold0 5.2803 → **5.1862(w=0.15, −0.094)** — 事前学習前からブレンド寄与が出る。
### 相関の全体像(fold0, pp後)
- pooled: img 7.106 / GBM 5.280 / TCN 5.140 / blend 5.056
- corr: **img-GBM 0.584 / img-TCN 0.476** / GBM-TCN **0.889(現行2脚はほぼ双子)**
- blend+img(w0.15)= **4.953(−0.103)** / 3脚線形 best 4.939(−0.117)— 事前学習前・fold0。

### P1 第1試行(2026-07-12): 失敗
- 合成1000本(THICK0.06/WARP3/NOISE7)事前学習 → fold0 fine-tune **7.290(なし7.106より悪化)**。
- 原因: **T0/T1難易度ゲートを飛ばしてT2直行**(手順ミス)。合成val 9.4=実(7.1)より難しすぎ/ノイズ過多の分布ミスマッチ。
- リトライ手順: ノブ2-3セットを「合成の画像脚難易度 ≈ 実7.1±1」ゲートに通す → 3000本 → 低LR fine-tune。
