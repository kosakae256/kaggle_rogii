# v78 — 非逐次推定ファミリーの逐次実装(K16錨付き) ★ユーザー方針 2026-07-22

## 方針(ユーザー確定)
- **族5(直接回帰=GBM/TCN/CNN)は「最終的に入力するモデル」=消費者**。v77成果はサイドカー特徴として
  最終的にチェーンへ入る(素材準備済、末尾)。
- **v78の本体 = 残りの推定ファミリー(族2:大域最適化/族4:アライメント/族6:ベイズサンプリング)を
  錨付きで一つずつ実装**。錨が井戸定常バイアス(誤差構造法則の毒)を殺した今なら、
  過去に死んだ族も正しい効果を得られる可能性がある(ユーザー読み)。
- 評価: wids[::5] 155井標本(60井スクリーン禁止) → 勝ちは773井 → blend判定(vs PF+錨+P5+P6=7.128)。

## 実装ロースター(P番号継続, 実装順)
### P18: ロバスト遷移FB(族1→2の橋: line processの厳密1D版) — 最初(最安)
- P6の遷移カーネルを **混合 (1−p)·N(0,σ_rw) + p·N(0,σ_jump)** に置換。「まれに大きく跳ぶ」を
  厳密FBのまま表現(Blake-Zisserman弱膜のexact版)。datum両義の枝替え(±15ft)をジャンプとして扱う。
- 掃引: p∈{0.003,0.01,0.03} × σ_jump≈15ft。
### P19: 因子グラフ・バッチ最適化(族2本命)
- 行ごと連続オフセット変数 + ①GRロバスト尤度因子(Cauchy) ②隣接平滑因子(robust=跳び許容)
  ③錨因子(σ(dd)) を一括最小化(torch/IRLS)。P10(低次元スプライン)との違い=行変数+ロバスト結合で
  **区間ジャンプを表現できる**。
### P20: tempered MCMC / 焼きなまし(族6)
- 軌跡全体を状態に parallel tempering。多峰(±15ft両義)を温度で越える。posterior mean出力。
  コスト高→31井(::25)で機構検証→155。
### P21: DTW/OT アライメント(族4)
- TVT非単調への対処: 区間内単調(dip符号固定)×区間切替のhybrid DP、またはOTソフトアライメント。
### P22: GP回帰(族6, 低優先)
- offset(MD)にGP事前+非ガウス尤度。FBとの差分=長距離相関のみ→効果薄の読みで最後。

## 結果
### P18 ロバスト遷移FB(ジャンプ混合) — ★close
JP=0.003/0.01/0.03 → 8.057/8.072/8.116(155標本, 基準P6 emt015=7.784)。**単調悪化**。
機構: EMT軟化FBは既に事後を両義に分散させており、明示ジャンプ質量はエイリアス吸引にしかならない。
含意: ロバスト/重尾の「遷移」系(truncated pairwise含む)はこの問題では不要=P19の飽和平滑因子にも同じ懸念。
### P19 因子グラフ・バッチ最適化 — ★close
ANCW{1.0,0.1,0.03}×W_SM{10,50,200}×W_GR{1,3}×GRMA{1,13} 全構成 8.449〜8.479 ≥ 錨8.448。
**一度も錨を超えられない**。機構: 多峰事後(±15ft両義)では点推定(バッチMAP)が原理的に不利。
GRの局所勾配は正しい盆地を選べず、Adamは初期値(錨)近傍の鞍を彷徨うだけ。
**FB(厳密周辺化→posterior mean)が同じモデルで7.78を出す=族2連続最適化は族1の下位互換で確定**。
### P20 設計変更(重要): MCMC→「井戸レベル大域潜在の周辺化」へ
FB既存モデルのMCMC近似は無意味(FBが厳密解)。族6の実質=FBが扱えない**大域潜在変数**:
GRレベルシフトb×typewellストレッチsのグリッドでFBを回し、**FB周辺尤度(logZ)でソフト混合**。
(TWREF点推定補正は死んだが、周辺化は過信しない=原理的に正しい形。)
### P20/P21' 結果(31井::25標本, P6 emt015基準=7.689 / 錨8.145)
| 変種 | 31井 | 判定 |
|---|---|---|
| P20 bias×stretch(5×3) | 7.631 | 錨・P6超え |
| **P20 biasのみ(5×1)** | **7.619** | ★最良。stretchは無価値 |
| P21' (offset×bias)2D同時FB | 7.798(BRW無反応) | P6より悪い=biasドリフト自由度はエイリアスに悪用 |
- 機構: 効くのは「bias格子の証拠重み付き混合」(重みmax中央0.22=緩い周辺化)。上乗せ−0.07級。
- **族4(DTW/OT)は実装省略の判断**: 1D格子上のアライメントはFB/DPに数学的に帰着
  (warp自由度=offset随歩と等価)。単調制約はP5のdip状態が既に担う。新情報軸なし。
### P20 155井確認 — ★反転でclose
bias単独P20 @155 = **8.167 > P6 emt015 7.784**(同一標本)。31井の−0.07は小標本の錯覚
(31→155でも順位反転=標本サイズ法則3例目。**31井スモークすら判定に使えない、155が最低ライン**)。

## P30 「非逐次化されたPF」= r0モデルの厳密2D-FB(ユーザー発案) — ★最重要の負結果
r0の力学・emission・初期化を忠実に格子化(状態=S偏差±150×rate±0.09, 決定的)。
| 構成 | 31井(::25) pooled | 中央 |
|---|---|---|
| 全区間平滑 | 38.4 | 9.6 |
| 固定ラグ16(厳密) | 32.6 | 11.7 |
| 固定ラグ64(厳密) | 33.0 | 11.9 |
| (参考)素PF r0_seed32 | ~8.6 | — |
5井スモークでは井戸別にPF圏内(1井はPF超え7.2vs10.3)だが、広げると少数井で大暴走。
### ★実験的結論: PFが効く本当の理由
1. **逐次性ではない**(同じモデルの厳密事後=FBはPFより遥かに悪い)。
2. **平滑地平でもない**(厳密lag16でも暴走は消えない)。
3. 消去法で残る本質 = **リサンプリングによる経路縮退(モード・コミット)+32seed×尤度softmax混合**。
   モデルは誤較正(エイリアスに過大な尤度質量)されており、厳密posterior meanは両モードの間に落ちる。
   PFの「欠陥」(粒子退化=1モードに固執)が偶然にも「接続された・datumから育つ・単一モード」への
   暗黙priorとして働き、32seedの尤度混合が良いコミットを選ぶ。
   = v34モードゲート(LB5.930)・v47「壁は枝判別」と同じ絵に合流する。
### 次の一手(P31候補): 厳密事後の「モードベース復号」
K-best Viterbi(ジャンプ禁止=接続強制)でモード束を列挙 → 各モードのevidence(路の周辺尤度)で混合
= 32seed PFの決定的上位互換の正しい形。(乱数でなく構造でモードを列挙する。)
### P31 K-mode Viterbi + evidence混合(決定的32seed) — 初版はPF未達
5井: P31 12.7-15.7(MT 5/15/20全て) vs PF 8.9 / P30 12.5。井戸別はPF圏内(00e12e8bでは8.2 vs PF10.3)だが
平均で届かない。モード彫り出し(±4ft封鎖)のスコアはPFのllと整合せず混合が機能していない。
### ★P30/P31シリーズの科学的総括
「PFの強さ」の候補を潰した順: ①逐次性×(厳密FBが大負け) ②平滑地平×(厳密lag16も同じ)
③モードコミット+尤度混合×(決定的K-mode列挙もPF未達)。
残る候補=**リサンプリング時のroughening(rp0.76の位置ジッタ=ESS低下時に自動で太くなる適応拡散)**
などPF固有の適応雑音、あるいは検証精度の問題(SUBK量子化/彫り出し幅)。
実利判断: P30/P31はP5/P6ファミリーを超えない見込みが濃い→ここで区切り、
チェーン統合(train_tabular_v78=サイドカー14列)の実測を優先するのが正。
