# v88 — GR表現とPF「尤度計算」の変更で自己相似性に勝つ

> ユーザー指示(2026-07-24 夜): 「GR自体の表現や、PFのGR尤度の計算方法を変更した場合に精度が向上するか。
> **特に尤度の計算方法を変更するのが重要かもしれない**。GRは自己相似性のため追従できないことがあり、
> それを解決するために導入されたのが self/neighbor だった。今は個別に計算しているが、
> **typewell/self/neighbor で尤度自体を計算したらどうなるか**が気になる。
> また、**そもそも自己相似性を解決できる方法でGRマッチをしているかも分かっていない**。そのあたりを実験してほしい」
> 追記: 「v65の合成尤度エンジンにこだわらなくてよい(あまりうまくいかなかった記憶)」

## 問題の本質(なぜ今の尤度では自己相似性に勝てないか)
現行のGR尤度は **各MD行で独立の点照合**:
```
lk_i = exp(-0.5 · ((GR_obs(md_i) − GR_ref(tvt_i)) / σ)^power)
```
- GRは準周期(Milankovitch)なので、TVTを1サイクル(≈±15ft)ずらしても **GR系列がほぼ同じ**。
- 逐次の積で証拠は貯まるが、**ずらした枝も同じだけ貯まる**ので比が縮まらない＝**データを増やしても曖昧性は解けない**。
  ([[v47-selection-ceiling]] の「datum両義行=全13-20%がRMSE72%、判別~56%頭打ち」はこの帰結)
- ∴ **点照合を続ける限り原理的に解けない**。勝つには尤度に「サイクルを区別する情報」を入れるしかない。

## 効きうる軸(既知の法則から)
- ★[[v76]]/[[v78]]の鉄則: **絶対GRレベルを消す表現は死**(生点差分7.784 ≫ 勾配8.97 ≫ NCC15.5)。
  = **絶対レベルと低周波こそが反エイリアス信号**。サイクルは同形でも「どのサイクルか」はレベル/長波長が持つ。
- [[v85]]: GR別表現(logamp/affine/bandcap)は**単体では勝てず脱相関blend脚**にしかならなかった。
  → 表現を"差し替える"のは筋が悪い。**尤度に"足す(多チャネル化)"方が理に適う**。
- [[v65合成尤度PF]]: tw/self/nbrのemission積。未tuneでtw+nbr −2.66/self β1で過信悪化。
  ユーザー記憶では「あまりうまくいかなかった」→ **1データ点として測るが主軸にしない**。

## E2 多チャネル尤度(LF/HF分離) — ★失敗(重み単調悪化)。ただし重要な原理を確定
200井・対照r0=7.2001。`lk=exp(-0.5[ (d_raw/σ_raw)^p + w_lf(d_lf/σ_lf)^p (+ w_hf …) ])`、
LF=観測をMD平滑(r_md=100ft)・参照をTVT平滑(r_tvt=4ft)。
| 構成 | RMSE | Δ | ρ(vs r0) |
|---|---|---|---|
| raw1+lf0.5 | 10.530 | +3.330 | 0.669 |
| raw1+lf1.0 | 13.476 | +6.276 | 0.499 |
| raw1+lf2.0 | 17.123 | +9.923 | 0.348 |
| raw1+lf4.0 | 20.410 | +13.210 | 0.267 |
| lf1+hf1(raw off) | 15.720 | +8.520 | 0.376 |
| lf2+hf1(raw off) | 18.157 | +10.957 | 0.332 |
- **重みに対して単調悪化**=偶然でなく構造的な誤り。blendでも w≈0.05 しか乗らず脚としても無価値。
- ★**診断(この失敗の意味)**: 観測は **MD領域**、参照は **TVT領域**に住む。両者を別々に平滑すると、
  **MD→TVTの倍率(=dip)が坑井ごと・区間ごとに異なり、しかもそれ自体が推定対象**なので、
  「同じ低周波成分」を比較していることにならない。LF残差は位置依存の系統誤差となりPFを引きずる。
- ★★**一般則(以後の設計指針)**: **観測をMD方向に変換(平滑/勾配/窓)して参照のTVT方向変換と比べる尤度は原理的に不成立**。
  点照合(obs(md_i) vs ref(tvt_i))だけが領域整合。文脈を使いたいなら
  **粒子自身の rate(dTVT/dMD)でMD窓をTVT窓へ写像する**しかない。→ E4 を主軸に格上げ。

## E4 文脈マッチ(粒子rateでMD窓→TVT窓) — ★失敗(窓が長いほど単調悪化)
200井・対照r0=7.2001。粒子の(pos,rate)仮説の下で、直近span ft の観測列を参照と照合し
`dp += (w/K)·Σ_j |(obs(md_i−Δ_j) − ref(pos − rate·Δ_j − z))/σ|^p` を加算。
| 構成 | RMSE | Δ | ρ |
|---|---|---|---|
| ctx k4 span200 w1.0 | 8.104 | +0.903 | 0.850 |
| ctx k8 span400 w0.5 | 10.094 | +2.894 | 0.738 |
| ctx k8 span400 w1.0 | 10.273 | +3.073 | 0.714 |
| ctx k8 span400 w2.0 | 11.145 | +3.945 | 0.620 |
| ctx k16 span800 w1.0 | 11.600 | +4.399 | 0.633 |
| ctx k8 span800 w1.0 | 11.832 | +4.632 | 0.647 |
- **span が長いほど単調に悪化**(200→400→800 で +0.90→+3.07→+4.63)。
- ★**診断**: 粒子の rate は**局所の線形外挿**。実際の軌跡は dip が折れる区分線形
  ([[error-anatomy-ref]]「parallel jagged lines」)なので、**長い窓ほど過去位置の予測が外れ**、
  正しい粒子にまで大きな偽残差を課す。→ 窓長に対して単調悪化、という観測と完全に整合。
- ★★**一般則2**: **一定rateの外挿に依存する文脈項は使えない**(dipが折れるため)。
  E2の一般則と合わせ、**「観測側を長い区間にわたって変換/投影する尤度」は全て筋が悪い**。

## E2/E4 の共通教訓 → 方針転換
- どちらも「モデル仮定(平滑対応/一定dip)が破れると**系統的に偏った項**を尤度に足す」形だった。
  偏った項の追加は、何も足さないより悪い。
- 一方 [[v51-method-exploration]] で成功した尤度改変(NN-emission)は **重み W≈0.02 の極小**だった。
  → 「尤度に足す」なら**極小重みの穏やかなnudge**でなければならない可能性が高い。
- 次: **tw だけでは原理的に解けない**([[error-anatomy-ref]]「最悪十分位ではoracle較正でも真TVT近傍の
  GR-misfitが平坦/反転」)以上、**外部情報(self/nbr)を尤度に入れる**のが本筋。
  ただしPFを回す前に、**E1診断でself/nbrが実際に判別力を足すのかを測る**(無駄弾を撃たない)。

## E1 曖昧性の解剖(診断) — ★「現行の点照合は自己相似性を全く解けていない」を定量化
200井/3141区間/区間長300行。真TVT軌跡を δ だけ平行移動したときのミスフィット断面 S(δ) を実測。
**hit@2ft = argmin_δ が |δ|≤2ft に入る率**、**margin = (|δ|≥5ftの最小S − S(0))/|S(0)|**。
| 参照 | hit@2ft | margin中央 | margin>0率 | \|decoyδ\|中央 |
|---|---|---|---|---|
| tw | 39.5% | −0.256 | 30.1% | 16.5 |
| self | 32.7% | −0.126 | 30.1% | 11.5 |
| nbr | 15.9% | −0.574 | 12.9% | 15.5 |
| tw+0.25self | **43.8%** | −0.083 | 39.7% | 14.0 |
| tw+0.5self | 42.9% | **−0.081** | **39.8%** | 13.5 |
| tw+1.0self | 40.9% | −0.081 | 38.2% | 13.0 |
| tw+nbr | 28.6% | −0.328 | 23.9% | 15.0 |
| tw+self+nbr | 34.6% | −0.137 | 32.1% | 13.5 |
- ★**tw単体は hit 39.5%・margin中央が負(−0.256)・margin>0率30%**。
  = **70%の区間で「真の位置より良く合うデコイが存在する」**。デコイδ中央16.5ft=サイクル周期。
  → ユーザーの問い「そもそも自己相似性を解決できるGRマッチをしているのか」への答えは **NO(全く解けていない)**。
- ★**self を足すと判別力が上がる**(hit 39.5→43.8%, margin −0.256→−0.083)。**β_self≈0.25-0.5 が最適**。
- ★**nbr は判別力を下げる**(tw+nbr 28.6% < tw 39.5%)。以後 nbr は主軸から外す。
- 注意: 診断はargminのみ見るのでPFの粒子退化を被らない。**PFでの検証が必須**(下記)。

## E5 tw+self 合成尤度 — ★★2つの実装バグを潰して初めてプラス
### 潰したバグ(いずれも「部分被覆の参照を尤度に足す」時の一般的な罠)
1. **欠測に0を入れていた** → 未被覆位置が「ミスフィット0=最良」に見え、粒子を未観測領域へ引き寄せる。
2. **中立定数(NEUTRAL/mref)の事前推定が外れる** → 診断B(真TVT上の実測, 80井)で判明:
   self は真の位置で **dmed=0.031(twの0.042より良い)** のに、センタリング定数が
   フォールバックの **1.000** のままだった(ホールドアウト較正はTVT被覆重複が足りず殆ど発火しない)。
   結果 `cwt·(0.031−1.000)≈−0.97` の巨大な負寄与が付き、**GR適合と無関係に self被覆帯へ強烈に引き寄せ**。
   → **σ_self を大きくすると更に悪化**(E5b: β0.1で15.5)したのはこのため(定数ズレが拡大)。
   - 参考実測(80井): tw σ41.6/被覆100%/dmed0.042、self σ40.6/**被覆27.6%**/dmed0.031、nbr **被覆1.2%**/dmed0.057。
     ※σが gr_sig_max=45 に張り付き **1行あたりの識別力は極めて弱い**(exp(-0.5·0.04)≈0.98)。累積で効かせる設計。
### 解法: **行ごとに粒子群平均を引く**(部分被覆チャネル専用、tw は不変で base回帰維持)
中立定数の事前推定は原理的に困難なので、`term -= term.mean(粒子)` で
「全粒子に一律に効く成分(=被覆の有無そのもの)」を消し、**粒子間の相対的な合致差だけを残す**。

## E3 識別力(distinctiveness)重み — ★失敗(2度)。打ち切り
`dp ← dp·U(tvt)`(U小=自己相似)。200井: a0.3 で +1.86、a1.0 で +3.23。
- 原因: **dpを直接掛けると「曖昧な位置(U小)ほど dp が小さい=良い」となり逆効果**。
- 修正版(レベル不変・コントラストのみ圧縮 `dp ← mean + U·(dp−mean)`)でも a0.3 +1.86 / a0.6 +3.41 と失敗。
- → 自己相似度で尤度の鋭さを変調する筋は**否定**(blend脚としても w=0)。

### ユーザーの問いへの回答
1. **「そもそも自己相似性を解決できるGRマッチをしているか」→ NO**。
   tw点照合は hit@2ft **39.5%**、margin中央が**負**、**70%の区間で真の位置より良く合うデコイが存在**(周期16.5ft)。
2. **「typewell/self/neighborで尤度自体を計算したらどうなるか」→ self は有効、nbr は有害**。
   - self を尤度に入れると判別力が上がる(診断 hit 39.5→43.8%)。PFでは**極小重み(β≈0.05-0.1)**でのみ成立し、

   - nbr は判別力を下げる(診断 tw+nbr 28.6% < tw 39.5%、被覆1.2%)。**尤度に入れない**。

### 一般則(v88で確定した設計則。今後の尤度改変は全てこれに従うこと)
1. **観測(MD領域)を変換して参照(TVT領域)の変換と比べる項は不成立**(E2)。MD→TVT倍率=dipが未知かつ推定対象。
2. **一定rateの外挿に依存する文脈項は不成立**(E4)。dipが折れる(区分線形)ため窓が長いほど破綻。
3. **部分被覆の参照を尤度に足す時は、欠測に0を入れてはならない**(未観測領域が最良に見える)。
   中立定数の事前推定も外れる。**行ごとに粒子群平均を引く**のが唯一堅牢(=相対情報のみ残す)。
4. **自己相似度で尤度の鋭さを変調する筋は死**(E3, 2度)。
5. **尤度への追加項は極小重み**([[v51]] W≈0.02 と整合)。β>0.2 は必ず壊れる。
6. **200井の単体優位は773井で消える**(β0.02, pn0.01 で2度実証)。**blend利得は200/773で一致し再現する**。

## E12 行ごとの情報量重み(GRの希少性で行の証拠力を変える)
仮説: typewellのGR分布で**希少な値**が観測された行は位置特定に強く効き、**ありふれた値**の行は効かない。
`dp_i ← dp_i · w_i`(w_i=観測GRの情報量 −log p(GR) を平均1に正規化)。粒子間では一様なので
**行間の証拠力配分**を変える(=どの行を信じるか)。点ごと・領域整合で一般則に抵触しない。
