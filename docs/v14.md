# v14

> v13 の PF 画像データ(波形+GR)を使い、**U-Net 以外の「画像的」TVT抽出法を10種**比較する。
> 古典CV/DP系の教師なし読み出し。良いものがあれば採用候補。
> 最終更新: 2026-06-29

## 位置づけ
- v13 で作った per-seed 波形(`fwd_traj_*`/`bwd_traj_*`)+ GR から **(H,T) 画像**(順方向密度・逆方向密度・GR尤度)を作り、
  **学習なし**で各MD列の TVTオフセットを読み出す。
- 軸: y=中心(center=順方向PF平均)からの相対TVT(ft), x=MD。予測=各列オフセット → `pred_rel`。
- 評価: `target_rel`(=真TVT−center)基準の **overall RMSE**(全坑井プール)= TVT RMSE。学習不要なのでCV不要。
- ベースライン: center(offset0, =pf_ancc 相当)。

## 10手法 [v14/image_methods_v14.ipynb](../v14/image_methods_v14.ipynb)
1. 順方向密度 argmax
2. 逆方向密度 argmax
3. 順×逆 積 argmax(一致ピーク)
4. 順×逆 積 soft-argmax(期待値)
5. GR尤度 argmax(セミブランス的)
6. 順×逆×GR 積 argmax(PF+GR融合)
7. 順×逆×GR 積 soft-argmax
8. **DP/Viterbi(融合コスト上の平滑最短経路)**(L1遷移ペナルティ, numba)← 本命の画像法
9. DP/Viterbi(GRコストのみ)
10. 順×逆積 argmax → Savitzky-Golay 平滑(稜線デノイズ)

- 密度は **全PFセット(pf_1/2/3)の波形を合算**してKDEヒストグラム化。GR尤度は typewell から再計算(PF不要)。
- 画像パラメータ: BAND=32, BINW=0.5(H=129)。DP_LAM=0.3(ビンあたり遷移ペナルティ)。

## 結果(全手法 baseline 未満=採用なし)
- baseline center(offset0)= **9.277**。**全10手法がこれを下回れず**。
  - 最良: fb prod softargmax 9.499 / all prod softargmax 9.517(centerにほぼ並ぶがわずかに劣る)
  - argmax系 11.3〜11.6(列ごとargmaxは飛んでノイジー)
  - DP/Viterbi 11.34(all)/12.97(gr)(強いが誤った稜線に確信を持って乗る)
  - GR系 最悪(gr argmax 19.39 / DP gr 12.97)
- 所感:
  - **単純な画像読み出し(教師なし)はPF平均(pf_ancc)を超えない**。soft-argmaxは密度平均≈PF平均を再現するだけ。
  - **点GRコストは弱い/有害**(gr系が壊滅)→ 「点GR→窓付きNCCサーフェス」にすべき、が裏付けられた。
  - 超えるには (a) 学習(U-Net/CNN)か (b) GR表現の改善(窓付き正規化相互相関)が必要。固定読み出しでは不可。
