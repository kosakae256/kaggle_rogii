# v15

> v13 の生PFデータ(per-seed波形+GR)から、**手法ごとに合った入力表現を on-the-fly 構築**して
> 学習する CNN系 5手法を 5-fold で比較。良いものは採用候補。
> 最終更新: 2026-06-29

## 位置づけ
- v13 は画像を事前生成して U-Net 1種。v15 は **生波形から各手法用の表現をその場で作る**(画像は保存しない)。
- 線描画は「線が通った所を染めるだけ(生カウント/S, ぼかし無し)」。
- 評価: GroupKFold(5) by well, OOF全行プールの overall RMSE(target_rel基準=TVT RMSE)。
- ベースライン参考: v10(LGBM,2)=7.554 / v12(TCN)=7.871 / v13 U-Net(pf_1)=8.583 / pf_ancc≈9.188。

## 5手法 [v15/cnn_methods_v15.ipynb](../v15/cnn_methods_v15.ipynb)
1. **m1_unet**   : 2D U-Net。(3,H,T)=順密度/逆密度/GRコスト → ヒートマップ → soft-argmax
2. **m2_dilated**: 2D dilated all-conv(解像度維持, 残差)→ ヒートマップ
3. **m3_bandch** : 1D-CNN。密度(H,T)を H=チャンネルとして MD方向1D畳み込み → オフセット回帰
4. **m4_summary**: 1D-TCN。各MDで順/逆の平均/std/分位点(10/50/90)/差 + GRコスト最小オフセット を要約(12ch)→ 回帰
5. **m5_hybrid** : 2D画像エンコーダ(H方向平均集約)+ 1Dサマリ を結合 → 回帰

- 入力は全て center 相対。密度は pf_1/2/3 全波形を合算。GR は typewell から(PF不要)。
- 学習: T方向ランダムクロップ(CROP=768)、損失=ヒートマップはCE+soft-argmax MSE / 回帰はHuber、early stopping。
- OOF を `v15/artifacts_v15/oof_{method}.npz`(well→pred_rel)に保存 → v10/v12/v13 とブレンド可能。
