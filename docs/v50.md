## 仮説(v50 の出発点)
これまでの PF フリー(v40/v43/v44/v48)が 8.8〜9.7 に張り付いたのは、デコーダの差ではなく
**全員が同じ証拠=生GR振幅の点毎コスト `|g−f|` を使っていたから**。v47 の「枝判別 全軸56%頭打ち」も
固定表現での測定にすぎない。→ **鍵は GR の表現**。真の対応 `(t, y_true)` は train に数百万ペアあるので、
「真の一致とサイクルゴーストを分離する表現」を**対応点学習(対比学習)**で直接作れるはず。

## Stage A(分水嶺測定)の設計
- **エンコーダ2本**(dilated 1D CNN, 0.3M): 水平坑行特徴 a_t(GR多スケール/微分/局所分散/ロバストz/
  デトレンドz/dZdMD の8ch)× typewell格子特徴 b_k(0.5ft格子, 7ch)。cosine類似 = 学習emission。
- **損失**: InfoNCE(soft CE, 真値ビン±45ft band 181bin)+**ゴーストhinge**
  (band内・真値から6ft以遠の最強競合 vs 真値近傍±2ft, margin 0.1)= ゴースト分離を明示的に教える。
- **評価(井戸レベル分割, val坑井のみ)**:
  1. 行レベル判別: 真値近傍(±2ft)スコア > 遠方(≥6ft)最強競合スコア の勝率、top1(±3ft)
  2. **A2**: v48 grid filter(FB, SIGG6/TAU0.35/LPR0.3)の emission を差し替えて同一デコーダ比較

### 知見
- **表現は明確に学習できる**(3倍)。しかも**生との積(product of experts)が最強**=学習表現は生振幅と
  相補の情報(波形テクスチャ)を拾っている。学習単体(7.58)< 生(7.22)に負けるのに積で 6.36 になるのが証拠。
- **温度較正が生死を分ける**: 学習logitをそのまま使うと過剰確信で 11.5 まで悪化。行softmax(温度0.3前後)
  →ビン内確率平均(混合)が正解。最適は (t0.3〜0.4)×(w0.4〜0.5) のプラトー(頑健)。
- ユーザー基準: rmse15 突破 ✓ / **物理prior単体(struct 8.45)を 2.1ft 上回る** ✓。

## ★研究総括(Stage A/B 完了時点, 2026-07-11)
**効いたもの(実証済みレバー)**
1. **GR表現は学習できる**: 対応点対比学習+ゴーストhinge → 行判別 生の3.1倍(0.11→0.41)。
   歴代PFフリー8.8-9.7張り付きの真因は「全員が生振幅コストという同じ証拠」だったこと。
2. **相補性**: 学習表現単体<生 だが **積(product of experts)最強** = 学習表現は波形テクスチャという別軸。
3. **デコーダ学習は「固定FBの上位互換」構造が必須**: FB事後γ入力なしでは固定FBに勝てない。
   難foldほど改善=較正頑健化を学習が吸収。
4. **nbr=唯一の本物の独立情報**(単体もブレンド床も動かした)。self は冗長(v27再現)。
5. 受容野dil16 / 容量 / 較正ずれ増強 / 温度較正 が累積(各−0.05〜−0.15)。

**効かなかったもの(構造的理由)**: flip(証拠が時間非対称)/ stride8・格子細分(bin平均の
スムージングが仕事)/ 合成事前学習(fold間ばらつき増)/ nbr k16重み(fold0中立)。

**限界の構造**: 単体7.778・blend7.240で増分縮小。残る誤差=井戸まるごとbimodalな硬い核
(fold3≈9.8が頑固)。現decoder=posterior mean は**両峰の中間へのヘッジ**しかできない。
プロジェクト知見との接続: 誤差72%=datum両義行(v47)/ soft生・hard死(v29/v34)/
**井戸レベル枝分類は学習可能(v33 AUC0.82, v34 gate LB5.930)**/ hengck23「候補生成を作り直せ」。

### 診断(leave-field-out+選択的ゲート, `stageC_diag_v50.py`, 2026-07-11)
- **①データはほぼ単一巨大フィールド**: XY単連結クラスタで 741/773井が10kmしきい値で1塊(5kmでも303+170が2大塊)。
  → leave-field-out は縮退して検証不能。井戸5foldの数字=実力。
  (含意: 相互nbrプールがLBで効く(v27)のは test も同一エリアだから、と整合)
- **②選択的ゲートは全τで負け**: τ0.7(36介入)でも 7.897 > base 7.880。
  介入必要井戸(167井)の枝ランキング正解率 0.389(チャンス0.17の2.3倍=信号はある)が、
  base最良井戸での誤介入傾向(top≠base 89%)が強く、最確信の介入でも勝率<5割。
- **★結論: 壁= CVスキームでなく特徴の情報量**。単一モデルの事後質量+パス沿い集計では
  枝の真偽を裏付ける独立の証人が不足。v33のAUC0.82は複数エンジンの外部票があってこそ。
- **次に攻めるなら**: 仮説ごとの「外部票」特徴 = 生emissionのみFB / nbrのみFB / struct のみ、
  各々が各シフトを支持するかの独立票(PFフリー内での多陪審員化)。+prefix接続整合。
