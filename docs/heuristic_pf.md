# PF出力ヒューリスティック探索（ルール反復）

> PF 30出力（5表現×6バンク）を ML でなく**手作りルール**で集約する探索。ユーザー方針＝
> 「推論結果をよく見て傾向を掴み、ルールを決め、反復」。基準＝median30（overall RMSE 6.667, ::3）。
> ML blend 天井＝5.987。作成 2026-07-31。

## 誤差構造（イテレ0-1で観察）
- median30=**6.667**。**84.4%は枝0で正確(|e|2.1)、残り15.6%が±15ft枝で|e|12+** ＝ここが全RMSE源。
- **spread(30のstd)が誤差を綺麗に予測**: 低spread 2.3 → 高spread 11.3。
- **井戸内の枝一貫性＝中央値93%**。92%の井戸は枝0正しい。誤枝の内訳＝**井戸丸ごと逆枝33% / 孤立segment飛び67%**。
- per-row oracle=2.22（発散域でも30本のどれかは真値近く＝情報は扇の端にある）。
- 井戸多数派枝に全行を寄せる天井（真値使用）＝**5.794**。

## 井戸軌跡の可視化で見えたこと（scratchpad/wells_flip.png）
- 序盤(低MD)は30出力が真値にピタリ密集 → **高MDで扇状に発散**（不確実性がアンカー距離で増大）。
- **真値は扇の"中心"でなく"端/外"に居ることが多い** ＝ median(中心)は大変動を減衰して外す。
- 飛びは単発スパイクでなく **segment長のラン**（∴ rolling平滑は無効）。

## ★確定した法則
1. **枝/経路にコミットする系は全敗**（密集モード・連続トラッカ・α増幅・枝投票）。
   理由＝**両義性は対称**なので、コミット外し(−15) > medianのヘッジ(−7.5)。**medianの強さ＝ヘッジ**。
2. **medianを超えるのはソフトヘッジのみ**＝怪しい行(高spread)を井戸背骨(大窓median)へ寄せる。
   - 機構: `w = sp/(sp+3)`, `pred = med + w·(backbone_win201 − med)`。
   - **held-out検証: train median6.655→soft6.617 / val median6.680→soft6.646（−0.034転移＝本物）**。
   - magic number でなく1パラ機構。overfitでない。
3. **井戸長・Z分散の制御は spread に内包され上乗せ無し**（長い/高Z分散/高MD行は自ずと高spread）。
4. **どの井戸spread層でも median が最強**（易3.66/中5.81/難9.26、代替は全て負け）。
   ＝生の30出力の集約は median-hedge が天井。ML利得(6.667→5.987)は行ごとの特徴重み付けで、
   単純ルールには再現困難。

## 結論と次
- **生PF出力のヒューリスティック天井 ≈ 6.63**（median −0.034, 検証済）。ML blend 5.987 には遠い。
- 生出力に無い**唯一の直交信号 = 井戸間の空間整合**（近傍井戸のTVT面と±15ずれる井戸＝丸ごと逆枝を検出・補正）。
  = 5.794天井の realizable 化候補。**但し v42 で「空間はmedian改善するがtail悪化」**の前科あり（要精度検証）。
